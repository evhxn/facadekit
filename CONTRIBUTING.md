# Contributing to FacadeKit

Thank you for helping. FacadeKit is free and open source software under GPL-3.0-or-later.

## Plan and tickets

Work is planned as tickets in [tasks/](tasks/). Pick a ticket and do only what it says.

## Branches

Use one branch per ticket.

## Before a pull request

Run the checks before you open a pull request:

```
make lint test
```

## Contracts

The contracts between modules are in [docs/05-interfaces.md](docs/05-interfaces.md). Do not change them without discussion first. The repository layout is in [docs/04-repo-structure.md](docs/04-repo-structure.md).

## Licence and sign-off

Contributions are licensed under GPL-3.0-or-later (see [LICENSE](LICENSE)). Sign off each commit with the Developer Certificate of Origin by using `git commit -s`.
