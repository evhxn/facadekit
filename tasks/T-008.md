## Goal

Define the `Camera` and `ProjectorDisplay` protocols and build a simulator (virtual house wall, projector and webcam) that implements them. Every calibration and end-to-end test in the project runs against this simulator because builders and CI have no projector.

## Files to create

- `studio/backend/src/facadekit/devices/base.py`
- `studio/backend/src/facadekit/sim/scene.py`
- `studio/backend/src/facadekit/sim/devices.py`
- `studio/backend/tests/test_sim.py`

## Interfaces (copied from docs/05-interfaces.md) – implement exactly

Conventions: colour images are BGR `uint8` `(H, W, 3)`; sizes are `(width, height)`; homographies are `float64 (3,3)` named `h_<from>2<to>`.

```python
# devices/base.py
class Camera(Protocol):
    @property
    def resolution(self) -> tuple[int, int]: ...          # (width, height); valid after open()
    def open(self) -> None: ...                            # FkError CAMERA_OPEN_FAILED
    def close(self) -> None: ...
    def read(self) -> np.ndarray: ...                      # newest frame, BGR uint8; FkError CAMERA_READ_FAILED
    def set_controls(self, *, auto_exposure: bool | None = None, exposure: float | None = None,
                     auto_wb: bool | None = None, autofocus: bool | None = None) -> dict[str, bool]: ...
        # returns {name: applied?} only for the arguments that were not None. exposure is 0..1.

class ProjectorDisplay(Protocol):
    @property
    def size(self) -> tuple[int, int]: ...                 # (width, height) physical pixels
    def show(self, image: np.ndarray) -> None: ...         # (H, W) gray or (H, W, 3) BGR uint8, exactly `size`;
                                                           # returns only after the image is on screen.
                                                           # FkError BAD_IMAGE_SIZE on wrong shape

# sim/scene.py
Point = tuple[float, float]

@dataclass
class SimScene:
    world_size: tuple[int, int] = (1600, 900)
    proj_size: tuple[int, int] = (1920, 1080)
    cam_size: tuple[int, int] = (1280, 720)
    proj_corners_world: tuple[Point, Point, Point, Point] = ((150, 80), (1480, 40), (1520, 860), (110, 820))
        # where projector frame corners (0,0),(W,0),(W,H),(0,H) land on the world plane
    world_corners_cam: tuple[Point, Point, Point, Point] = ((90, 60), (1200, 95), (1180, 660), (70, 640))
        # where world corners (0,0),(1600,0),(1600,900),(0,900) appear in the camera image
    features_world: dict[str, tuple[float, float, float, float]] = field(default_factory=lambda: {
        "garage_door": (500, 480, 1100, 800), "window_left": (250, 200, 420, 380),
        "window_right": (1180, 200, 1350, 380)})         # (x0, y0, x1, y1) on the world plane
    occluders_world: list[tuple[float, float, float, float]] = field(default_factory=list)
    ambient: float = 0.05
    gain: float = 0.85
    gamma: float = 2.2
    blur_sigma: float = 1.0
    noise_sigma: float = 2.0
    seed: int = 0

    @property
    def h_p2w(self) -> np.ndarray: ...     # projector px -> world
    @property
    def h_w2c(self) -> np.ndarray: ...     # world -> camera px
    @property
    def h_p2c(self) -> np.ndarray: ...     # h_w2c @ h_p2w
    def albedo(self) -> np.ndarray: ...    # (900,1600,3) BGR uint8, cached
    def feature_quad_proj(self, name: str) -> list[Point]: ...   # ground-truth quad in projector px, TL,TR,BR,BL
    def render_camera(self, proj_image: np.ndarray | None, rng: np.random.Generator) -> np.ndarray: ...

def default_scene() -> SimScene

# sim/devices.py
class SimDisplay:   # implements ProjectorDisplay; size == scene.proj_size
    def __init__(self, scene: SimScene) -> None: ...
    current: np.ndarray | None      # last shown image, stored as (H, W, 3) BGR
class SimCamera:    # implements Camera; resolution == scene.cam_size
    def __init__(self, scene: SimScene, display: SimDisplay) -> None: ...
```

`render_camera` model (all float32 in 0..1 until the last step):

```
light_world = warpPerspective((proj_image/255) ** gamma, h_p2w, world_size)   # zeros if proj_image is None
light_world[occluder rectangles] = 0
radiance = albedo/255 * (ambient + gain * light_world)
cam = warpPerspective(radiance, h_w2c, cam_size)                               # black outside the wall
cam = GaussianBlur(cam, (0,0), blur_sigma) if blur_sigma > 0
cam = clip(cam * 255 + rng.normal(0, noise_sigma, cam.shape), 0, 255).astype(uint8)
```

`albedo()`: wall colour BGR `(60, 70, 150)`; mortar: horizontal lines 2 px thick every 24 px and vertical lines 2 px thick every 60 px (offset by 30 px on alternate rows) in BGR `(120, 120, 120)`; `garage_door` filled `(200, 200, 200)`; windows filled `(90, 60, 40)`; each feature has a 6 px frame `(30, 30, 30)`.

## Steps

1. `h_p2w = cv2.getPerspectiveTransform(projector corners, proj_corners_world)`; `h_w2c` likewise from world corners to `world_corners_cam`.
2. `feature_quad_proj(name)`: take the rectangle's corners in TL, TR, BR, BL order and map them through `inv(h_p2w)`. Unknown name → `KeyError`.
3. `SimDisplay.show`: validate shape against `size` (`FkError("BAD_IMAGE_SIZE")` otherwise); convert gray to BGR; store a copy in `current`.
4. `SimCamera`: owns `rng = np.random.default_rng(scene.seed)`; `read()` returns `scene.render_camera(display.current, rng)`; calling `read()` before `open()` raises `FkError("CAMERA_READ_FAILED")`. `set_controls` returns `True` for each non-None argument.
5. Use `cv2.INTER_LINEAR` for both warps. A projector pixel is smaller than a world pixel here, so fine stripes alias slightly; that is realistic and intended.

## Pitfalls

- `warpPerspective` takes `dsize=(width, height)`; do not swap.
- Keep `render_camera` under about 60 ms for 1080p input (tests call it ~120 times). Cache `albedo/255` as float32.
- `Protocol` classes must be importable without OpenCV side effects; `devices/base.py` imports only `numpy` and `typing`.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_sim.py && uv run mypy src && uv run ruff check .
```

Tests:

- `default_scene().h_p2c` maps `(0,0)` to the same point as `h_w2c` applied to `(150,80)` within 1e-6.
- `feature_quad_proj("garage_door")` mapped through `h_p2w` returns `(500,480),(1100,480),(1100,800),(500,800)` within 1e-6.
- With a white projector image, the camera pixel at the door centre (world `(800,640)` through `h_w2c`) is brighter than 150; with a black image it is darker than 30.
- Projecting an image that is white only left of projector column 960: camera pixel for projector point `(480,540)` (through `h_p2c`) is at least 80 levels brighter than for `(1440,540)`.
- An occluder covering the door makes the door centre dark even under white.
- `SimDisplay.show` with a wrong-sized image raises `FkError` `BAD_IMAGE_SIZE`.
- Same seed → identical frames from two fresh cameras.
