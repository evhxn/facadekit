# T-114 – Pair the video with an existing light sequence (.fseq)

- **Milestone:** v1
- **Recommended model:** Haiku
- **Depends on:** T-028, T-035
- **Parallel with:** T-112, T-113, T-115

## Goal

Let users who already run a pixel light show attach the FacadeKit video to one of the sequences on their Falcon Player (FPP), so lights and projection start together from one playlist entry.

## Background

FPP playlists can contain an entry of type `both`: a light sequence file (`.fseq`, made in xLights) plus a media file played together. If the FacadeKit show was built on the same song file, starting both at time 0 keeps them in sync. The backend's `publish_render` already accepts `sequence_name` and then writes `{"type": "both", "sequenceName": …, "mediaName": …}`.

## Files to create or modify

- Backend: modify `studio/backend/src/facadekit/api/routes_fpp.py`, `tests/test_api_render_fpp.py`; modify `fpp/fake.py` only if listing `sequences` is not already served by its generic `GET /api/files/{DirName}`
- Web: modify `studio/web/src/pages/publish/FppPanel.tsx`, `api/client.ts`, `pages/PublishPage.test.tsx`

## Interfaces available

```python
FppClient(host).list_files(dir_name) -> list[str]          # e.g. list_files("sequences") -> ["Carol.fseq", ...]
publish_render(host, local_path, *, media_name, playlist_name, start, sequence_name=None, ...)
# existing route: POST /api/v1/projects/{pid}/publish {host, render_id, playlist_name?, start, sequence_name?} -> 202 {job_id}
```

New route (prefix `/api/v1`): `GET /fpp/sequences?host=<host>` → `{"sequences": string[]}` (names ending `.fseq`, sorted case-insensitively). Unreachable FPP → `{"sequences": []}` with HTTP 200. Host validation as in the other FPP routes (reject `/ ? # @` and whitespace with 422).

## Specification

1. Client: `fppSequences(host): Promise<{sequences: string[]}>`; `publish` body gains optional `sequence_name` and `include_audio_note` is not needed.
2. FPP panel: after a successful Connect, load sequences. Show a select "Play together with a light sequence": "None (video only)" + the names. Help text: "Choose the sequence that uses the same song. FPP will start the lights and the projection together."
3. When a sequence is chosen:
   - The publish request includes `sequence_name`.
   - Show a warning box: "Your light sequence and this video should not both play the song. Render the video **without audio**, or remove the audio from the sequence's playlist entry." with a button "Render without audio now" that starts a render with `include_audio: false` and selects it when done.
   - Default playlist name becomes `FacadeKit - <project name> + <sequence name without extension>`.
4. Remember the last chosen sequence per project in `localStorage` (key `fk.seq.<project id>`), not in `project.json`.
