## Goal

Show each calibration pattern on the projector, photograph it with the camera, and return the stack of captured images. Before scanning, run checks that turn common setup mistakes into clear error codes.

## Algorithm

Helper `_shoot(display, camera, image, settings, sleep) -> tuple[gray float32, bgr uint8]`:

```
display.show(image)
sleep(settings.settle_ms / 1000)
repeat settings.discard_frames times: camera.read()
frames = [camera.read() for _ in range(settings.average_frames)]
bgr = mean of frames (float) rounded to uint8
gray = cv2.cvtColor(bgr, COLOR_BGR2GRAY).astype(float32)       # computed from the averaged frame
```

`precheck`:

```
if display.size != (spec.width, spec.height): raise RESOLUTION_MISMATCH
          message: "Projector window is {w}x{h} but the project expects {W}x{H}."
black = _shoot(all-zero image); white = _shoot(all-255 image)          # use default CalibSettings()
contrast = white_gray - black_gray
thr = max(12.0, 0.15 * percentile(contrast, 95))
lit = contrast > thr
lit_fraction = lit.mean()
if lit_fraction < 0.05: raise CAMERA_NO_PROJECTION
median_contrast = median(contrast[lit])
if median_contrast < 20: raise TOO_BRIGHT
return both numbers
```

`run_capture`:

```
controls = camera.set_controls(auto_exposure=False, auto_wb=False, autofocus=False)
# exposure search (only if controls["auto_exposure"] is True):
#   for e in (0.6, 0.5, 0.4, 0.3, 0.2, 0.1):
#       camera.set_controls(exposure=e); shoot white; if percentile(gray, 99) < 250: break
frames = pattern_sequence(spec)
for i, f in enumerate(frames):
    if cancel and cancel(): raise FkError("CANCELLED", "Calibration cancelled")
    gray, bgr = _shoot(render_pattern(spec, f))
    images[i] = gray; if f.kind == "white": white_bgr = bgr
    progress((i + 1) / len(frames), f"Pattern {i + 1} of {len(frames)}")
```

## Pitfalls

- Use the injected `sleep` everywhere (tests pass `lambda s: None` to run instantly). Never call `time.sleep` directly.
- Pre-allocate `images` as `np.empty((N, Hc, Wc), np.float32)`; for a 720p camera and 38 frames this is about 140 MB, which is acceptable. Do not keep per-frame BGR copies.
- `percentile(contrast, 95)` can be ≤ 0 when nothing is projected; `thr` then falls back to 12.
- Do not call `precheck` from `run_capture`; the pipeline (T-014) calls both so their progress can be reported separately.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_calib_capture.py && uv run mypy src && uv run ruff check .
```

Tests (simulator, `sleep=lambda s: None`, `CalibSettings(discard_frames=0, average_frames=1)` for speed):

- `precheck` on `default_scene()` returns `lit_fraction > 0.2` and `median_contrast > 40`.
- A display whose size differs from the spec → `RESOLUTION_MISMATCH`.
- Scene with `gain=0.0` → `CAMERA_NO_PROJECTION`.
- Scene with `ambient=0.9, gain=0.05` → `TOO_BRIGHT` or `CAMERA_NO_PROJECTION` (either is acceptable; assert the code is one of the two).
- `run_capture` returns `images.shape == (38, 720, 1280)`, dtype float32, `white_bgr.shape == (720, 1280, 3)`; progress was called 38 times ending at 1.0; mean of the white image exceeds mean of the black image.
- `cancel=lambda: True` raises `FkError` with code `CANCELLED`.
