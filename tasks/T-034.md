# T-034 – Media library and Arrange page

- **Milestone:** MVP
- **Recommended model:** Sonnet
- **Depends on:** T-029, T-033
- **Parallel with:** T-031, T-032, T-035

## Goal

Build the page where the user imports media, places clips on surfaces in time, plays the show with audio in a live preview (in the editor and on the house), and checks the exact rendered frame when paused.

The MVP deliberately uses a **clip list with form fields** plus a read-only timeline strip. Drag-and-drop timeline editing is a v1 ticket (T-102).

## Files to create or modify

Under `studio/web/src/`: `pages/ArrangePage.tsx`, `pages/arrange/MediaLibrary.tsx`, `pages/arrange/ClipList.tsx`, `pages/arrange/ClipForm.tsx`, `pages/arrange/TimelineStrip.tsx`, `pages/arrange/PreviewPane.tsx`, `pages/arrange/transport.ts`, `pages/arrange/clipOps.ts`, CSS modules, tests `pages/arrange/clipOps.test.ts`, `pages/arrange/transport.test.ts`, `pages/ArrangePage.test.tsx`.

## Interfaces available

```ts
// api/types.ts (T-029): Project, Asset, Clip, Track, Timeline, Surface, newId(prefix)
interface Clip { id; asset_id: string | null; generator: null; surface_id: string; start_ms: number; duration_ms: number;
  in_offset_ms: number; loop: boolean; fit: "fill" | "fit" | "stretch"; opacity: number;
  fade_in_ms: number; fade_out_ms: number; blend: "normal" | "add" | "screen" }
interface Track { id: string; name: string; clips: Clip[] }          // tracks[0] is the bottom layer
interface Timeline { duration_ms: number; audio_asset_id: string | null; tracks: Track[] }
// api/client.ts
uploadAsset(pid, file, onProgress?): Promise<{asset: Asset; project: Project}>
deleteAsset(pid, aid): Promise<Project>            // ApiError code ASSET_IN_USE
assetUrl(pid, aid): string        assetThumbUrl(pid, aid): string
frameUrl(pid, tMs, scale): string                  // exact backend-rendered JPEG
projectorShow({mode: "compositor" | "blank", project_id}): Promise<ProjectorStatus>
projectorTransport({project_id, playing, t_ms, revision}): Promise<void>
// state/projectStore.ts
useProjectStore: { project, update(mutator), saveNow(), replace(project), dirty, saving }
// gl/compositor.ts (T-033)
new PreviewCompositor(canvas, { assetUrl: (assetId) => string }); .setProject(project); .render(tMs, playing); .dispose()
```

Project validation rules enforced by the backend (the UI must never produce a violation): clips on the same track must not overlap in time; `clip.surface_id` is a surface id or `"canvas"`; `clip.asset_id` must be a video or image asset; `timeline.audio_asset_id` must be an audio asset or a video with `has_audio`; `duration_ms > 0`; `opacity` 0–1.

## Specification

**Media library (left column)**

- "Import" button and drag-and-drop zone accepting multiple files; each upload shows a progress bar; on success call `store.replace(result.project)` (the server already added the asset). Errors show `userMessage`.
- Grid of assets: thumbnail (audio shows a note icon), name, duration, size. Delete button (on `ASSET_IN_USE` show "Remove the clips that use this file first.").
- Audio assets have a "Use as show audio" button that sets `timeline.audio_asset_id` and, if the timeline has no clips yet or its duration is the default 60000, sets `timeline.duration_ms` to the audio's duration.

**Clip list (centre)**

- "Add clip" opens the form with defaults: first video/image asset, first surface (or `canvas` if none), `start_ms: 0`, `duration_ms: timeline.duration_ms`, `loop: true`, `fit: "fill"`, `opacity: 1`, fades 0, `blend: "normal"`.
- Table of clips sorted by track then start: asset name, surface name, start, duration, loop, blend. Selecting a row opens `ClipForm`: asset select, surface select (surfaces + "Whole frame (canvas)"), layer select (Track 1…N, "New layer on top"), start and duration in seconds (one decimal; stored as ms), in-offset, loop, fit (Fill / Fit / Stretch with one-line explanations), opacity slider, fade in/out seconds, blend (Normal / Add / Screen with the hint "Use Add or Screen for videos with a black background").
- Timeline settings: duration in seconds; show-audio select (None + eligible assets).

`clipOps.ts` (pure functions, unit-tested) is the only code that mutates tracks:

```ts
export function addClip(project: Project, clip: Clip, trackIndex: number | "new"): void;
  // inserts into the track; if it would overlap another clip there, places it on the first higher track where it
  // fits, creating a new top track ("Track N") if needed
export function updateClip(project: Project, clipId: string, patch: Partial<Clip>): void;
  // applies the patch; if the result overlaps on its track, moves the clip to the first track where it fits (searching upward), creating one if needed
export function moveClipToTrack(project: Project, clipId: string, trackIndex: number | "new"): boolean;  // false if it would overlap
export function removeClip(project: Project, clipId: string): void;      // also drops tracks left empty, except keeps at least one track
export function overlaps(a: Clip, b: Clip): boolean;                     // half-open intervals
export function findClip(project: Project, clipId: string): { track: Track; clip: Clip } | null;
```

**Timeline strip (bottom)**: read-only canvas or DOM: one row per track (top track drawn at the top), clip bars positioned by time with the asset name, a time ruler in seconds, and a playhead. Clicking the strip seeks; clicking a bar selects that clip.

**Preview pane (right/top)**

- A canvas with backing size = projector size ÷ 2 (CSS-scaled to fit) driven by `PreviewCompositor`.
- Transport: Play/Pause (Space), Stop (returns to 0), time readout `m:ss.s`, seek via the strip.
- `transport.ts`: `class Transport { play(); pause(); seek(tMs); get tMs(); get playing(); onTick(cb) }`. If the timeline has audio, an `<audio>` element (src = `assetUrl`) is the clock: `tMs = audio.currentTime * 1000`; otherwise use `performance.now()`. Reaching `timeline.duration_ms` stops and rewinds. The class takes a clock/audio abstraction in its constructor so tests can drive it.
- On every animation frame while playing (and on any project or seek change while paused) call `compositor.render(tMs, playing)`.
- **Exact frame**: when paused for more than 400 ms, load `frameUrl(pid, tMs, 0.5)` (after `saveNow()`) and show it over the canvas with a small "exact" badge; hide it as soon as playback or editing resumes. If the request fails, keep showing the WebGL preview.
- **Show on house** toggle: on → `saveNow()`, `projectorShow({mode: "compositor", project_id})`, then send `projectorTransport({project_id, playing, t_ms, revision})` on play, pause, seek, after each save (new revision), and every 2 s while playing (drift correction). Off or page leave → `projectorShow({mode: "blank"})`. Handle `PROJECTOR_NOT_CONNECTED` like T-032 (turn off, show note).

## Pitfalls

- Never write seconds into the project; convert to integer milliseconds with `Math.round(seconds * 1000)`.
- `store.update` mutators must use `clipOps` so the no-overlap rule always holds; otherwise the auto-save PUT fails with `INVALID_PROJECT`.
- Audio `currentTime` updates coarsely in some browsers; between updates interpolate with `performance.now()` but never run ahead by more than 100 ms.
- Deleting a surface is handled elsewhere; if a clip references a missing surface (should not happen), show it as "Missing surface" and exclude it from preview.

## Acceptance

```
cd studio/web && pnpm lint && pnpm typecheck && pnpm test
```

Tests:

- `overlaps` is false for touching clips (`a` ends exactly when `b` starts).
- `addClip` onto a track where it overlaps places it on the next track, creating "Track 2" when needed.
- `updateClip` lengthening a clip into its neighbour moves it up a track; `removeClip` drops an emptied upper track but keeps the last remaining track.
- `moveClipToTrack` returns false on overlap and leaves the project unchanged.
- `Transport` with a fake clock: play advances `tMs`, pause freezes it, seek sets it, reaching the duration stops at 0.
- Page test (mocked API, store and `PreviewCompositor`): adding a clip through the form results in a store project with one clip with the default values; setting duration "12.5" stores `12500`; choosing an audio asset as show audio sets `audio_asset_id` and the timeline duration; a failed delete with `ASSET_IN_USE` shows the specified message.

Manual check in `--sim` mode with a sample video: preview plays in the editor.
