## Goal

One function that takes a rendered MP4 and gets it playing on the user's Falcon Player (FPP): check the FPP version, upload, verify, create the playlist, optionally start it.

## Interfaces (copied from docs/05-interfaces.md)

FppClient(host, *, timeout=10.0)

To implement:

```python
VIDEO_DIR = "videos"       # FPP media directory for video files [assumption; spike S-1]

def sanitize_name(name: str) -> str
    # keep [A-Za-z0-9._-], replace every other character with "_", collapse repeated "_",
    # prefix "fk_" if the result does not already start with it, keep the extension
def media_entry(media_name: str, sequence_name: str | None = None) -> dict[str, Any]
def probe_fpp(host: str) -> dict[str, Any]
    # {"reachable": bool, "version": str | None, "major": int | None, "ok": bool, "problems": list[str]}
    # never raises for an unreachable or odd FPP
def publish_render(host: str, local_path: Path, *, media_name: str, playlist_name: str, start: bool,
                   sequence_name: str | None = None,
                   progress: Callable[[float, str], None] | None = None,
                   cancel: Callable[[], bool] | None = None) -> dict[str, Any]
    # returns {"media_name": str, "playlist_name": str, "started": bool}
```

Playlist entries:

```json
{"type": "media", "enabled": 1, "playOnce": 0, "mediaName": "fk_garage-2026.mp4", "videoOut": "--Default--"}
```

With `sequence_name`: `{"type": "both", "enabled": 1, "playOnce": 0, "sequenceName": "song.fseq", "mediaName": "fk_garage-2026.mp4", "videoOut": "--Default--"}`.

## Steps

`publish_render`:

1. `local_path` must exist → else `FkError("NOT_FOUND")`. `media_name = sanitize_name(media_name)`.
2. `client.version()`; `major < 10` → `FkError("FPP_TOO_OLD", "FPP {version} found. FacadeKit needs FPP 10 or newer.")`.
3. Progress budget: version 0–0.02, upload 0.02–0.92 (rescale the client's callback), verify 0.92–0.95, playlist 0.95–0.98, start 0.98–1.0. Messages: "Checking FPP", "Uploading", "Verifying", "Creating playlist", "Starting".
4. Verify: `media_name in client.list_files(VIDEO_DIR)` → else `FkError("FPP_UPLOAD_FAILED", "Upload finished but FPP does not list the file.")`.
5. `client.put_playlist(playlist_name, [media_entry(media_name, sequence_name)])`.
6. If `start`: `client.start_playlist(playlist_name)`.
7. Always `client.close()` in `finally`.

`probe_fpp`: unreachable → `reachable False`, `problems ["Could not reach FPP at <host>. Check the address and that the Pi is on the same network."]`; `major < 10` → `ok False`, problem "FPP <version> is too old. Update FPP to version 10 or newer."; otherwise `ok True`, empty problems.

`sanitize_name("My Show (final).mp4") == "fk_My_Show_final_.mp4"`.

## Pitfalls

- Playlist names may contain spaces and dashes; they are passed through unchanged (the client percent-encodes them). Empty playlist name → `FkError("BAD_REQUEST")`.
- Do not stop a currently playing playlist unless `start` is true; uploading while a show runs must be safe.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_fpp_publish.py && uv run mypy src && uv run ruff check .
```

Tests with the `fake_fpp` fixture:

- Happy path with `start=True`: result `started` true; file present on the fake under `videos/` with the sanitised name; stored playlist has one `media` entry with that `mediaName` and `videoOut == "--Default--"`; fake status is `playing`; progress non-decreasing ending at 1.0.
- `start=False`: fake stays `idle`.
- `sequence_name="song.fseq"` → entry `type == "both"` with `sequenceName`.
- Fake created with `version="9.4"` → `FkError` `FPP_TOO_OLD` and no file uploaded.
- Missing local file → `NOT_FOUND`.
- `probe_fpp` on the fake → `{"reachable": True, "ok": True, "major": 10, …}`; on a closed port → `reachable False` with one problem string; on the 9.4 fake → `ok False`.
- `sanitize_name` cases: the example above; `"fk_x.mp4"` unchanged; `"äö.mp4"` → `"fk_.mp4"` is not acceptable: when the stem becomes empty use `"fk_show.mp4"`.
