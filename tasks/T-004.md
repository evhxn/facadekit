## Interfaces (copied from docs/05-interfaces.md) – implement exactly

All models use `model_config = ConfigDict(extra="forbid")`.

```python
Point = tuple[float, float]                      # (x, y) projector pixels

class ProjectorSpec(BaseModel):
    width: int = 1920                            # 160..4096
    height: int = 1080                           # 90..2160
    fps: int = 30                                # one of 24, 25, 30, 50, 60

class Mask(BaseModel):
    outer: list[Point]                           # >= 3 points
    holes: list[list[Point]] = []

class Mesh(BaseModel):
    cols: int                                    # 1..16
    rows: int                                    # 1..16
    offsets: list[Point]                         # (cols+1)*(rows+1) entries, row-major

class Surface(BaseModel):
    id: str
    name: str
    quad: tuple[Point, Point, Point, Point]      # TL, TR, BR, BL
    mask: Mask | None = None
    feather_px: float = 0.0                      # 0..200
    aspect: float                                # > 0
    mesh: Mesh | None = None

class Asset(BaseModel):
    id: str
    kind: Literal["video", "image", "audio"]
    filename: str
    original_name: str
    width: int | None
    height: int | None
    duration_ms: int | None
    fps: float | None
    has_audio: bool = False
    has_alpha: bool = False

class Generator(BaseModel):
    type: Literal["solid", "wash", "outline", "strobe"]
    params: dict[str, float | str] = {}

class Clip(BaseModel):
    id: str
    asset_id: str | None
    generator: Generator | None = None
    surface_id: str                              # a surface id or "canvas"
    start_ms: int                                # >= 0
    duration_ms: int                             # > 0
    in_offset_ms: int = 0                        # >= 0
    loop: bool = True
    fit: Literal["fill", "fit", "stretch"] = "fill"
    opacity: float = 1.0                         # 0..1
    fade_in_ms: int = 0                          # >= 0
    fade_out_ms: int = 0                         # >= 0
    blend: Literal["normal", "add", "screen"] = "normal"

class Track(BaseModel):
    id: str
    name: str
    clips: list[Clip] = []

class Timeline(BaseModel):
    duration_ms: int = 60000                     # > 0
    audio_asset_id: str | None = None
    tracks: list[Track] = []

class Marker(BaseModel):
    t_ms: int
    kind: Literal["beat", "downbeat", "onset", "user"]

class FppTarget(BaseModel):
    host: str | None = None
    playlist_name: str | None = None

class Project(BaseModel):
    schema_version: Literal[1] = 1
    id: str
    name: str
    revision: int = 0
    projector: ProjectorSpec = ProjectorSpec()
    calibration_id: str | None = None
    surfaces: list[Surface] = []
    assets: list[Asset] = []
    timeline: Timeline = Timeline()
    markers: list[Marker] = []
    fpp: FppTarget = FppTarget()
```

Cross-field validation on `Project` (a `model_validator(mode="after")`):

1. Ids unique within `surfaces`, `assets`, `tracks`, and across all clips.
2. Every `clip.surface_id` is `"canvas"` or an existing surface id.
3. Every non-null `clip.asset_id` exists and is not an audio asset; `timeline.audio_asset_id`, if set, is an audio asset or a video asset with `has_audio`.
4. Exactly one of `clip.asset_id` and `clip.generator` is non-null.
5. Clips on a track, sorted by `start_ms`, do not overlap.
6. A surface id may not be `"canvas"`. `Mesh.offsets` length equals `(cols+1)*(rows+1)`.

## Steps and pitfalls

- Use `Field(ge=…, le=…)` for the numeric ranges in the comments. For `fps` use `Literal[24, 25, 30, 50, 60]`.
- Validation failures must surface as pydantic `ValidationError` (callers convert to `FkError("INVALID_PROJECT")`). Provide a helper in `project.py`: `def parse_project(data: Any) -> Project` that catches `ValidationError` and raises `FkError("INVALID_PROJECT", <first error message with its location>)`.
- Mutable defaults: use `Field(default_factory=…)` for lists and nested models.
- Add `def utc_now_iso() -> str` in `jobs.py` returning e.g. `"2026-11-09T21:14:03Z"`.
