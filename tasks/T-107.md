# T-107 – Model download manager

- **Milestone:** v1
- **Recommended model:** Haiku
- **Depends on:** T-003
- **Parallel with:** T-101, T-102, T-104, T-110

## Goal

Download optional AI model files on first use into the user's data folder, verify them with SHA-256, and never re-download a good file.

## Files to create

- `studio/backend/src/facadekit/ai/models.py`

## Steps

1. Also expose `def registry() -> dict[str, dict[str, Any]]` and allow an override path through env `FACADEKIT_MODEL_REGISTRY` (used by tests and by users who mirror models).
2. `ensure_model(name)`: unknown name → `FkError("NOT_FOUND")`. If `models_dir()/filename` exists and its SHA-256 matches → return it. Otherwise download with `httpx.stream("GET", url, follow_redirects=True, timeout=30)` to `<filename>.part`, hashing while writing and reporting `progress(bytes / total, "Downloading <name>")` when `Content-Length` is known; on completion compare the hash; mismatch → delete and raise `FkError("MODEL_DOWNLOAD_FAILED", "Checksum mismatch for <name>")`; success → `os.replace` to the final name.
3. Any network error or non-200 status → `FkError("MODEL_DOWNLOAD_FAILED", "Could not download <name>. Check your internet connection.")`. A registry entry whose `sha256` still starts with `TO_BE_FILLED` → `FkError("MODEL_DOWNLOAD_FAILED", "Model <name> is not published yet.")` without any network call.
4. A per-name `threading.Lock` prevents two simultaneous downloads of the same file.
5. Only `https://` URLs are accepted (`file://` additionally allowed when env `FACADEKIT_MODEL_REGISTRY` is set, for tests).

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_ai_models.py && uv run mypy src && uv run ruff check .
```

Tests (serve a small file from a local `http.server` thread or use a `file://` URL with a temp registry; set `FACADEKIT_DATA` to `tmp_path`): first call downloads and returns a path with the right content; second call makes no request (delete the source file to prove it); wrong hash → `MODEL_DOWNLOAD_FAILED` and no file or `.part` file left; unknown name → `NOT_FOUND`; placeholder hash → `MODEL_DOWNLOAD_FAILED` with "not published"; unreachable URL → `MODEL_DOWNLOAD_FAILED`.
