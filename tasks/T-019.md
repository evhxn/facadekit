# T-019 – Render pipeline, outline frame and alignment-check video

- **Milestone:** MVP
- **Recommended model:** Sonnet
- **Depends on:** T-005, T-017, T-018

## Goal

Render a whole project to an MP4 (compositor frames → encoder, with progress and cancel), and produce the surface-outline image and the short "alignment check" video users play through FPP to confirm the projection lines up.

Frame time rule: frame `n` has `t_ms = n * 1000 // fps`.

## Steps

`render_project`:

1. Load the project; resolve the preset; `w, h = output_size(preset, W, H)`; `scale = w / W`. Create `Compositor(project, project_dir, scale=scale)`. If `compositor.size != (w, h)` (rounding), resize each frame with `cv2.resize(..., INTER_AREA)`.
2. Audio: if `include_audio` and `timeline.audio_asset_id` is set, `audio_path = project_dir / asset.filename`; else `None` (the encoder writes silence).
3. Loop frames; check `cancel()` every frame → `encoder.abort()`, close the compositor, raise `FkError("CANCELLED", "Render cancelled")`. Report progress at most every 0.25 s with message `"Frame {n} of {total}"`.
4. Write to `out_path.with_suffix(".part.mp4")`, and `os.replace` to `out_path` only after `encoder.close()` succeeds. On any exception delete the partial file.
5. Ensure `out_path.parent` exists.

`outline_frame`: use `cv2.polylines(..., isClosed=True, thickness=3, lineType=cv2.LINE_AA)`, `cv2.circle`, `cv2.putText` (`FONT_HERSHEY_SIMPLEX`, scale 0.8, thickness 2, white), text centred on the mean of the quad's corners.

`render_alignment_check`: build the two frames once; frame `n` uses the filled version when `(n * 2 // fps) % 2 == 1`.

## Pitfalls

- Always close the compositor in a `finally` block; it owns ffmpeg subprocesses.
- A timeline with zero clips is valid and renders black video with audio.
- `duration_ms` passed to the encoder is `frames * 1000 // fps`, not the timeline duration, so audio and video end together.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_render_pipeline.py && uv run mypy src && uv run ruff check .
```

Tests (projects built in `tmp_path` with `save_project_dir`; projector 320×180 @ 30; preset `preview-540p` to stay fast):

- 2 s timeline with one red image clip on a surface: output exists, `probe` says video, duration 1900–2100 ms, result `frames == 60`; decoding the middle frame with `VideoReader` shows a red-dominant pixel at the surface centre (R > 150, G < 80) and black in a corner (preview preset upscales 320→960, so test at proportional coordinates).
- With an audio asset as `timeline.audio_asset_id` → output `has_audio`; with `include_audio=False` still has a (silent) audio stream.
- `cancel` returning true after 5 calls → `FkError` `CANCELLED`; neither the output nor the `.part.mp4` file exists.
- Unknown preset → `UNKNOWN_PRESET`.
- Progress is non-decreasing and the last value is 1.0.
- `outline_frame` for a project with one surface: a pixel on the top edge midpoint is white, the quad interior is black with `fill=0` and about 26 gray with `fill=0.1`; `selected_id` makes the edge yellow.
- `render_alignment_check(..., seconds=2, preset_id="preview-540p")` produces a 2 s video.
