# T-031 – Projects page and setup wizard

- **Milestone:** MVP
- **Recommended model:** Sonnet
- **Depends on:** T-029, T-030
- **Parallel with:** T-032, T-033, T-034, T-035

## Goal

Build the first screens a new user sees: the project list (create / open / delete) and the setup wizard that walks through projector window, camera placement and the calibration scan, ending with the "projector view" photo.

## Product context

FacadeKit maps video onto a house. The user's laptop is connected to a projector (HDMI) and a USB webcam. The wizard shows stripe patterns through the projector while the webcam watches; the result is a photo of the house as seen from the projector, on which the user later draws surfaces. Users are hobbyist decorators, not engineers: one instruction per step, plain words, clear errors.

## Files to create or modify

Under `studio/web/src/`: `pages/ProjectsPage.tsx`, `pages/SetupPage.tsx`, `pages/setup/StepProjector.tsx`, `pages/setup/StepCamera.tsx`, `pages/setup/StepScan.tsx`, `components/JobProgress.tsx`, `components/ErrorBanner.tsx`, CSS modules, and tests `pages/SetupPage.test.tsx`, `pages/ProjectsPage.test.tsx`.

## Specification

### ProjectsPage (`/`)

- List projects (name, modified date) with Open and Delete (confirm dialog). "New project" form: name (required) and projector native resolution chosen from `1920×1080`, `1280×720`, `1280×800`, `854×480`, `800×480`, or Custom (width/height inputs); fps fixed at 30. Help text under the resolution field: "Use your projector's *native* resolution (see its manual or label), not the highest it accepts."
- After creating, navigate to `/p/<id>/setup`.

### SetupPage (`/p/:projectId/setup`), three steps with Back/Next

**Step 1 – Projector.**
- Text: "1. Connect the projector to this computer with HDMI. 2. Turn off keystone and digital zoom on the projector. 3. Open the projector window and drag it onto the projector screen, then click it to go fullscreen."
- Button "Open projector window" → `window.open("/projector", "fk-projector", "popup,width=800,height=600")`.
- Live status from `projectorStatus()` + `projector` events: not connected / connected with size. If the size differs from the project's projector size show the `RESOLUTION_MISMATCH` message with both sizes and block Next. When it matches, call `projectorShow({mode: "grid"})` once and show "You should see a white grid on the house. The projector may take 2 minutes to reach full brightness."
- In sim mode (`health().sim`) show a note "Simulator mode: no projector needed" and allow Next.

**Step 2 – Camera.**
- Camera picker from `listCameras()` (auto-select if only one; empty list → "No camera found. Plug in a USB webcam and click Refresh.").
- Live view: an `<img>` whose `src` is `cameraSnapshotUrl(cid) + "?t=" + Date.now()`, refreshed every 350 ms after the previous image has loaded (never overlap requests).
- Text: "Place the camera next to the projector, pointing at the house. The whole grid must be inside the picture. Fix the camera so it cannot move." Button "Show white" / "Show grid" toggles `projectorShow`.
- Exposure slider 0–1 (calls `setCameraControls` debounced 200 ms with `auto_exposure: false, exposure`), with a note when `applied.exposure` is false: "This camera does not allow exposure control. That is usually fine."

**Step 3 – Scan.**
- Buttons: "Start scan" and a secondary "Skip scan (manual mode)".
- Start → `startCalibration(pid, {mode: "scan", camera_id})`, show `JobProgress` (bar, message, Cancel). While scanning show "Do not walk in front of the projector."
- Failure: `ErrorBanner` with `userMessage(job.error.code, job.error.message)` plus Retry and "Use manual mode".
- Success: reload the project, fetch the calibration, show the projector-view image (`projViewUrl`) scaled to fit, and quality line "Measured {coverage %} of the projection." Warnings: `LOW_COVERAGE` → overlay the measured mask so unmeasured areas are tinted red, with the text "The camera could not see the red areas. Surfaces there may need manual alignment."; `NON_PLANAR` → "This wall is not flat. That is OK, but check alignment carefully."; `CAMERA_CONTROLS_UNAVAILABLE` → small grey note.
- Button "Continue to surfaces" → `/p/<id>/surfaces`. If the project already has a `calibration_id` when the page opens, start on step 3 showing the existing result with "Scan again".

### Shared components

- `JobProgress({job, onCancel})`: progress bar, message, cancel button (hidden in final states).
- `ErrorBanner({message, actions?})`.

Red tint overlay: draw the projector view on a canvas, then draw the mask image with `globalCompositeOperation` so that mask-black areas become `rgba(255,0,0,0.35)` (one way: draw the mask to an offscreen canvas, invert it with `difference` white fill, use it as alpha via `destination-in` on a red fill, then draw that over the photo).

## Acceptance

```
cd studio/web && pnpm lint && pnpm typecheck && pnpm test
```

Tests (React Testing Library, API module mocked with `vi.mock`):

- ProjectsPage lists mocked projects; creating one calls `createProject("Garage", {width: 1280, height: 720, fps: 30})` when 1280×720 is chosen and navigates to the setup route.
- Step 1 blocks Next while status is disconnected; shows the mismatch text when status is 1280×720 but the project is 1920×1080; enables Next and calls `projectorShow({mode:"grid"})` exactly once when sizes match.
- Step 2 with zero cameras shows the "No camera found" text; with one camera renders the snapshot image.
- Step 3: clicking Start calls `startCalibration` with the chosen camera; a mocked failed job with code `TOO_BRIGHT` shows the friendly message and a Retry button; a succeeded job shows the projector-view image and the coverage line; `LOW_COVERAGE` shows the red-area text.
- "Skip scan" calls `startCalibration(pid, {mode: "manual"})`.

Manual check: `uv run facadekit serve --sim --no-browser` + `pnpm dev`; complete the wizard in simulator mode and see the simulated facade photo.
