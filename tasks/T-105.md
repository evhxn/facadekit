# T-105 – Beat markers on the timeline and "cut on beats"

- **Milestone:** v1
- **Recommended model:** Haiku
- **Depends on:** T-102, T-103, T-104
- **Parallel with:** T-108, T-109, T-111

## Goal

Show beat markers on the timeline, let clips snap to them (snapping itself exists from T-102), let users add their own markers, and add a helper that splits a clip on every N-th beat.

## Files to create or modify

`studio/web/src/pages/arrange/Markers.tsx`, `pages/arrange/beatOps.ts` (+ test), `pages/arrange/Timeline.tsx`, `pages/ArrangePage.tsx`, `api/client.ts` (add `analyzeAsset`).

## Interfaces available

```ts
interface Marker { t_ms: number; kind: "beat" | "downbeat" | "onset" | "user" }       // project.markers, sorted by t_ms
// backend: POST /api/v1/projects/{pid}/assets/{aid}/analyze -> 202 {job_id}; job result {markers: number};
//          on success the server has replaced all non-user markers and bumped the revision (reload the project)
waitForJob(jobId, onUpdate?): Promise<Job>; userMessage(code, fallback)
useProjectStore: { project, update(mutator), load(id) }
interface Clip { id; start_ms; duration_ms; in_offset_ms; loop; … }      // clips on a track never overlap
// clipOps.ts: removeClip, addClip, findClip ; newId("clp")
```

## Specification

1. `analyzeAsset(pid, aid): Promise<{job_id: string}>` in the client.
2. Button "Find beats" next to the show-audio select: runs the job with a progress indicator, then reloads the project. Error `AI_UNAVAILABLE` shows: "Beat detection is not installed. See the docs to add it."
3. `Markers.tsx`: draws markers over the ruler and waveform rows: beats as thin lines, onsets as shorter fainter ticks, user markers as coloured flags. A toggle hides onsets (default hidden).
4. Press `M` during playback or when paused to add a `user` marker at the playhead; clicking a user marker selects it, Delete removes it. Only `user` markers are editable.
5. `beatOps.ts` (pure):
   - `beatsInRange(markers, startMs, endMs): number[]` (kind `beat` only).
   - `splitClipOnBeats(project, clipId, everyN: number): string[]` — replaces the clip with consecutive pieces cut at every N-th beat inside it (same track; each piece keeps all properties; for non-looping clips `in_offset_ms` advances by the elapsed time; for looping clips each piece keeps the original `in_offset_ms + elapsed` as well so playback is continuous). Returns the new clip ids. If fewer than one cut point lies inside the clip, it returns `[clipId]` unchanged.
   - `alternateSurfaces(project, clipIds, surfaceIds): void` — assigns surfaces round-robin to the given clips (a quick "bounce between windows" effect).
6. Context menu on a clip: "Split on every beat", "…every 2 beats", "…every 4 beats"; after a split, if two or more surfaces exist, offer "Alternate between surfaces…" with a surface multi-select.

## Acceptance

```
cd studio/web && pnpm lint && pnpm typecheck && pnpm test
```

Tests: `splitClipOnBeats` on a 0–4000 ms clip with beats every 500 ms and `everyN = 2` yields 4 pieces of 1000 ms that tile the original range without gaps or overlaps, with `in_offset_ms` 0, 1000, 2000, 3000; a clip with no beats inside is unchanged; `alternateSurfaces` cycles through the given ids; pressing `M` adds a `user` marker at the playhead time; "Find beats" calls `analyzeAsset` and reloads the project on success.

## Out of scope

Automatic show generation (v2), tempo editing, downbeats.
