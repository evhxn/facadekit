# T-116 – One-file installers for Windows and macOS

- **Milestone:** v1
- **Recommended model:** Sonnet (needs CI iterations; run spike S-7 first if `spikes/S-7-packaging.md` does not exist)
- **Depends on:** T-036 (complete MVP), T-107
- **Parallel with:** T-117

## Goal

Produce downloadable builds that non-technical users can run without installing Python: a Windows `.exe` and a macOS `.app` (zipped), built by GitHub Actions on tagged releases.

## Files to create or modify

- `packaging/facadekit.spec` (PyInstaller spec), `packaging/launcher.py`, `packaging/README.md`
- `.github/workflows/release.yml`
- `studio/backend/src/facadekit/cli.py` (small change: default command) and `tests/test_cli.py`

## Facts and constraints

- The app is the Python package `facadekit` (entry `facadekit.cli:main`); `facadekit serve` starts a local web server on port 8137 and opens the browser. The built web UI lives inside the package at `facadekit/webdist/` and must be included as data.
- Heavy dependencies: `numpy`, `opencv-python-headless`, `imageio-ffmpeg` (ships an ffmpeg binary inside the package under `imageio_ffmpeg/binaries/`, which must be collected), `uvicorn`, `fastapi`, `pydantic`. Optional `onnxruntime` and `librosa` (extra `ai`): include `onnxruntime`; **exclude `librosa`/`numba`** from the installer (large and fragile to freeze) and document that beat detection needs the pip install. The app must handle the missing import gracefully (it already raises `AI_UNAVAILABLE`).
- Model files are downloaded at run time (T-107), never bundled.
- Licence: GPL-3.0-or-later; the bundled ffmpeg is a GPL build. The installer must include `LICENSE` and a `THIRD_PARTY_NOTICES.txt` generated in CI (`pip-licenses --format=plain-vertical --with-license-file`).
- No code signing in this ticket. Document the unsigned-app warnings (Windows SmartScreen "More info → Run anyway"; macOS right-click → Open) in `packaging/README.md`.

## Specification

1. `packaging/launcher.py`: calls `facadekit.cli.main(["serve"])` when started with no arguments, otherwise passes arguments through. On startup failure (port in use, etc.) it shows the error in a console window and waits for Enter so the window does not vanish.
2. `cli.py`: if port 8137 is busy, `serve` tries 8138–8147 and prints the chosen URL (applies to all installs). Add `--port 0` semantics = pick a free port.
3. PyInstaller spec: `--onedir` layout wrapped as: Windows → a single self-extracting `.exe` is *not* required; ship a zip containing `FacadeKit/FacadeKit.exe` and its folder. macOS → `FacadeKit.app` (bundle id `org.facadekit.studio`), zipped. Console window enabled on Windows (users need to see the URL and errors). Collect data: `facadekit/webdist`, `facadekit/ai/model_registry.json`, `imageio_ffmpeg` binaries (`collect_data_files("imageio_ffmpeg", include_py_files=False)` plus binaries), uvicorn's hidden imports (`uvicorn.logging`, `uvicorn.loops.auto`, `uvicorn.protocols.http.auto`, `uvicorn.protocols.websockets.auto`, `uvicorn.lifespan.on`).
4. `release.yml`: trigger on tags `v*`. Jobs: (a) build web (`pnpm build`) and upload `webdist` as an artifact; (b) matrix `windows-latest`, `macos-14` (arm64) and `macos-13` (x64): download `webdist`, `uv sync --extra ai` minus librosa (install `onnxruntime` explicitly), `pyinstaller packaging/facadekit.spec`, **smoke test** (below), zip, upload; (c) create a GitHub Release with the zips, the wheel/sdist (`uv build`), and SHA-256 sums.
5. Smoke test in CI for each build: start the frozen app with `serve --no-browser --sim --port 8155` in the background, poll `http://127.0.0.1:8155/api/v1/health` until `status == "ok"` (timeout 60 s), fetch `/` and check it returns HTML containing `<div id="root">`, run the frozen app with `sim e2e` and require exit code 0, then stop the server.
6. `packaging/README.md`: how to build locally, how releases are produced, known warnings, where data is stored (`~/FacadeKit`).

## Pitfalls

- `opencv-python-headless` and PyInstaller: use the official hook; verify `cv2` imports in the smoke test (the `sim e2e` run covers it).
- `multiprocessing` is not used; do not add `freeze_support` unless needed.
- macOS camera permission: the `.app` needs `NSCameraUsageDescription` in `Info.plist` ("FacadeKit uses the camera to scan your projection.") or the OS kills the process on first camera access.
- Windows Defender may be slow on first run of unsigned binaries; nothing to do but document.

## Acceptance

- `uv run pytest -q tests/test_cli.py` passes, including a test that `serve` picks the next free port when 8137 is occupied (bind a socket in the test, call the port-selection helper directly).
- Pushing a tag `v0.0.0-test` on a fork produces three zips; the workflow's smoke tests pass on all three runners.
- Manual: download the Windows zip on a machine without Python, run `FacadeKit.exe`, the browser opens the UI, and `Setup` works in a project (camera list loads).

## Out of scope

Code signing and notarisation, auto-update, Linux packages (Linux users use `pipx`), an MSI/DMG installer, bundling AI models.
