# T-109 – Generator clips (built-in effects)

- **Milestone:** v1
- **Recommended model:** Sonnet
- **Depends on:** T-017, T-033, T-034
- **Parallel with:** T-105, T-108, T-111

## Goal

Add four built-in procedural effects that need no media file, so a user can light up surfaces and outlines in time with music immediately: solid colour, colour wash, outline trace, and strobe. Implement them identically in the Python renderer and the WebGL preview.

## Files to create or modify

- Backend: create `studio/backend/src/facadekit/render/generators.py`, `tests/test_render_generators.py`; modify `render/compositor.py`
- Web: create `studio/web/src/gl/generators.ts` (+ test); modify `gl/compositor.ts`, `gl/shaders.ts`, `pages/arrange/ClipForm.tsx`

## Interfaces (copied from docs/05-interfaces.md)

```python
class Generator(BaseModel):
    type: Literal["solid", "wash", "outline", "strobe"]
    params: dict[str, float | str] = {}
class Clip(BaseModel):  # exactly one of asset_id / generator is set
    asset_id: str | None; generator: Generator | None; surface_id: str; start_ms: int; duration_ms: int; opacity: float;
    fade_in_ms: int; fade_out_ms: int; blend: Literal["normal", "add", "screen"]; fit; loop; in_offset_ms
```

Compositing: a generator clip produces, for each frame, a colour image and an alpha defined **in the surface's unit square** `(u, v) ∈ [0,1]²` (u to the right, v down). It is then treated exactly like media with `fit="stretch"`: mapped through the surface homography, multiplied by the surface mask, clip opacity and fade, and blended. `tc` below is the clip-local time in seconds: `(t_ms − start_ms) / 1000`.

## Effect definitions (normative; both implementations must match)

Colours are `"#rrggbb"` strings. Defaults in brackets.

| Type | Params | Colour and alpha at (u, v, tc) |
|---|---|---|
| `solid` | `color` [`#ffffff`] | colour everywhere, alpha 1 |
| `wash` | `color_a` [`#ff0000`], `color_b` [`#0000ff`], `period_s` [4], `angle_deg` [0] | `p = u·cos(a) + v·sin(a)`; `m = 0.5 + 0.5·sin(2π·(p − tc / period_s))`; colour = `mix(color_a, color_b, m)`, alpha 1 |
| `outline` | `color` [`#ffffff`], `width` [0.03] (fraction of the unit square), `speed` [0.5] (laps per second), `tail` [0.35] (fraction of the perimeter) | `d = min(u, v, 1−u, 1−v)`; inside the border when `d < width`. Perimeter position `s ∈ [0,1)` of the nearest border point, measured clockwise from the top-left corner (top edge 0–0.25, right 0.25–0.5, bottom 0.5–0.75, left 0.75–1). `head = fract(tc·speed)`; `behind = fract(head − s)`; `a = behind < tail ? 1 − behind / tail : 0`. colour = `color`, alpha = `a` inside the border, 0 elsewhere. |
| `strobe` | `color` [`#ffffff`], `rate_hz` [8], `duty` [0.5] | on when `fract(tc·rate_hz) < duty`: colour, alpha 1; otherwise alpha 0 |

Nearest border point for `outline`: the edge with the smallest distance wins, ties broken in the order top, right, bottom, left; along the top edge `s = 0.25·u`, right `0.25 + 0.25·v`, bottom `0.5 + 0.25·(1−u)`, left `0.75 + 0.25·(1−v)`.

## Steps

Backend:

1. `generators.py`: `def render_generator(gen: Generator, tc: float, size: tuple[int, int]) -> np.ndarray` returning BGRA `uint8` `(h, w, 4)` evaluated on the pixel-centre grid `u = (x + 0.5) / w`, `v = (y + 0.5) / h`. Use `size = (256, 256)` for `wash` and `outline`, `(2, 2)` for `solid` and `strobe`. `parse_color("#rrggbb") -> (b, g, r)`; invalid strings fall back to white.
2. In `Compositor`, a generator clip yields this BGRA image as its source frame with `fit="stretch"`; the existing alpha path handles the rest. Remove the "skip generator clips" behaviour.

Web:

3. `generators.ts`: the same math as pure functions (`evalGenerator(gen, u, v, tc) -> {r, g, b, a}`) for tests, plus GLSL snippets. In the fragment shader add a `u_genType` uniform (0 = texture, 1–4 = generators) and uniforms for parameters; compute colour and alpha from `uv`.
4. `ClipForm`: a "Source" switch between Media and Effect. Effect shows a type select and parameter inputs (colour pickers, numeric fields with the defaults above). Switching sets `asset_id: null` and `generator`, or the reverse. `activeClips` no longer excludes generator clips.

Backend tests: `solid` red → all pixels `(0,0,255,255)`; `wash` at `tc=0`, angle 0: left column and right column colours follow the formula within ±2; `strobe` 1 Hz duty 0.5: alpha 255 at `tc=0.25`, 0 at `tc=0.75`; `outline` at `tc=0`, speed 0.5: pixel just right of the top-left corner on the top border has alpha ≈ 255·(1−~0/tail) (>240), the centre pixel alpha 0, and a border pixel at `s = 0.5` alpha 0; compositor: a `solid` green generator clip on a surface colours the surface centre green and respects opacity.

Web tests: `evalGenerator` matches the same numeric cases; `ClipForm` switching to Effect stores `asset_id: null` and a generator with defaults.

Add scenes `gen-wash` and `gen-outline` to the parity suite (`studio/web/e2e/scenes.ts`, T-037) at a fixed time and make them pass.
