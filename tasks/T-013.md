## Goal

Invert the decoded camera→projector correspondences into a smooth projector→camera lookup map, measure scan quality, and re-sample the camera photo into projector space. The result is the "projector view": a picture of the house as the projector sees it, on which users draw surfaces.

## Algorithm

```
W, H = spec.width, spec.height; G = grid_step
vs, us = nonzero(decoded.valid)                     # camera rows, cols
px, py = decoded.c2p[vs, us, 0], decoded.c2p[vs, us, 1]
if len(us) < 1000: raise SCAN_FAILED

# 1. accumulate camera coordinates into a coarse projector grid
gw, gh = W // G + 1, H // G + 1
j = clip(round(px / G), 0, gw - 1); i = clip(round(py / G), 0, gh - 1)
sum_u = bincount(i * gw + j, weights=us, minlength=gw * gh).reshape(gh, gw)   (same for vs, and counts)
measured_grid = counts > 0
grid_u, grid_v = sum_u / counts, sum_v / counts   (where measured)
coverage = measured_grid.mean()

# 2. global homography camera -> projector (sanity + hole filling)
pick up to 20000 random valid samples (np.random.default_rng(0))
h_c2p, inlier_mask = cv2.findHomography(cam_pts, proj_pts, cv2.RANSAC, 6.0)
planarity = inlier_mask.mean() if h_c2p is not None else 0.0

# 3. fill holes
w = measured_grid.astype(float32)
blur_u = GaussianBlur(grid_u * w, (0, 0), 2.0); blur_v likewise; blur_w = GaussianBlur(w, (0, 0), 2.0)
near = (~measured_grid) & (blur_w > 0.05)
grid_u[near] = blur_u[near] / blur_w[near]   (same for v)
far = (~measured_grid) & (~near)
if h_c2p is not None: grid[far] = apply(inv(h_c2p), cell centre (j * G, i * G))
else:                 grid[far] = nearest filled value (cv2.inpaint is not needed; use blur with larger sigma 8 as a fallback)

# 4. smooth and upsample
grid_u = cv2.medianBlur(grid_u.astype(float32), 3); same for v
p2c = cv2.resize(stack(grid_u, grid_v), (W, H), interpolation=INTER_LINEAR) -- see pitfall on alignment
measured = cv2.resize(measured_grid.astype(uint8), (W, H), interpolation=INTER_NEAREST).astype(bool)
```

`make_proj_view`: `cv2.remap(white_bgr, p2c[...,0], p2c[...,1], cv2.INTER_LINEAR, borderMode=cv2.BORDER_CONSTANT)`.

## Pitfalls

- **Grid alignment**: grid node `(i, j)` represents projector position `(j * G, i * G)`. `cv2.resize` assumes pixel-centre alignment and would shift the map. Instead build exact sample positions and interpolate with `cv2.remap` on the grid: `map_x = (xs + 0.5) / G` is wrong too. Use: for projector pixel centre `(x, y)`, grid coordinate `(x / G, y / G)`; then `p2c = cv2.remap(grid, gx.astype(float32), gy.astype(float32), INTER_LINEAR, borderMode=BORDER_REPLICATE)` where `gx, gy = meshgrid(arange(W) / G, arange(H) / G)`. `cv2.remap` samples at integer coordinates = node positions, which is exactly this convention.
- Decoded coordinates are cell centres (for example 2.0, 6.0, 10.0 … with `skip_lsb=2`), so rounding `px / G` distributes them over nodes without bias only when `G` is a multiple of the cell size `2**skip_lsb`. Assert `grid_step % (1 << spec.skip_lsb) == 0`, else `ValueError`.
- `np.bincount` weights are float64; convert results to float32 at the end.
- Division by zero where `counts == 0`: use `np.divide(..., out=zeros, where=counts > 0)`.
- `cv2.findHomography` can return `None` for degenerate input; handle it.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_calib_maps.py && uv run mypy src && uv run ruff check .
```

Tests:

- **Exact synthetic**: build a `DecodeResult` directly from a known homography `h_c2p_true` (camera 640×360, projector 640×360, all pixels valid, `c2p = apply(h_c2p_true, pixel)`). `build_maps` gives `coverage > 0.95`, `planarity > 0.99`, and for 200 random projector points inside the camera's footprint `|p2c[y, x] - apply(inv(h_c2p_true), (x, y))| < 1.0` px.
- **Simulator**: capture + decode `default_scene()` (as in T-012's test), then `build_maps`. For each corner of `scene.feature_quad_proj("garage_door")`, the camera position read from `p2c` differs from `apply(scene.h_p2c, corner)` by less than 2.5 px. `coverage > 0.85`, `planarity > 0.8`.
- **Projector view**: `make_proj_view(capture.white_bgr, maps)` has shape `(1080, 1920, 3)`; the pixel at the centre of the ground-truth garage-door quad is light (mean BGR > 120) and a pixel on the brick wall midway between the two windows is darker and redder (R channel > B channel).
- **Holes**: scene with an occluder `(700, 560, 900, 720)`; `measured` is False at the projector position of the occluder centre, and `p2c` there is still within 6 px of ground truth (filled from the homography/neighbours).
- Fewer than 1000 valid pixels → `FkError` `SCAN_FAILED`.
