# T-101 – Polygon masks with holes (editor + preview)

- **Milestone:** v1
- **Recommended model:** Sonnet
- **Depends on:** T-032, T-033
- **Parallel with:** T-102, T-104, T-106, T-110

## Goal

Let a surface have a free-form outline (and cut-out holes) in addition to its four mapping corners, so content can follow an arched window or avoid a house number. The Python renderer already supports masks; this ticket adds editing and WebGL preview.

## Background

A surface has a `quad` (4 corners that define how rectangular media is stretched) and an optional `mask`. When `mask` is null the visible area is the quad. When set, the visible area is `mask.outer` minus `mask.holes`, all in projector pixels. The backend rasterises it anti-aliased and blurs by `feather_px / 2` (Gaussian sigma).

## Files to create or modify

`studio/web/src/pages/surfaces/MaskEditor.tsx`, `pages/surfaces/polygon.ts` (+ test), `pages/surfaces/SurfaceCanvas.tsx`, `pages/SurfacesPage.tsx`, `gl/compositor.ts`, `gl/maskTexture.ts` (+ test for its pure parts).

## Interfaces (copied from docs/05-interfaces.md)

```ts
type Pt = [number, number];
interface Mask { outer: Pt[]; holes: Pt[][] }           // outer has >= 3 points
interface Surface { id; name; quad: [Pt, Pt, Pt, Pt]; mask: Mask | null; feather_px: number; aspect: number; mesh: Mesh | null }
```

Edits go through `useProjectStore.update(mutator)`. Live outlines on the projector use `projectorShow({mode: "outlines", project_id, selected_id})` (outlines show quads only; that is acceptable).

## Specification

1. Surface panel gains a "Shape" section: "Use corners (default)" / "Custom outline". Choosing custom initialises `mask.outer` from the quad.
2. Mask edit mode on the canvas: drag vertices; click an edge to insert a vertex; Delete/Backspace removes the selected vertex (minimum 3); "Add hole" draws a new polygon by clicking points and closing on the first point or with Enter; holes are editable the same way and removable. Arrow keys nudge the selected vertex (1 px, Shift 10 px).
3. Moving the whole surface moves quad and mask together.
4. `polygon.ts` pure helpers: `insertVertex(poly, edgeIndex, pt)`, `removeVertex(poly, i)`, `nearestEdge(poly, pt) -> {index, distance}`, `pointInPolygon(pt, poly)`, `translate(poly, dx, dy)`, `isSimple(poly)` (no self-intersection; show a warning when false).
5. WebGL preview: per surface with a mask, rasterise the mask into an offscreen 2D canvas at projector size ÷ 2 (fill outer white, holes black with `evenodd`, then `ctx.filter = blur(<feather_px/4>px)` because the canvas is half size), upload as an `R8`/`LUMINANCE` texture, and sample it in the fragment shader at `v_pos / projectorSize`, multiplying alpha. Rebuild the texture only when the mask or feather changes. Surfaces without a mask keep the existing analytic edge.
6. The exact backend frame (shown when paused) remains the reference.
