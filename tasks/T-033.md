# T-033 – WebGL preview compositor and homography math (TypeScript)

- **Milestone:** MVP
- **Recommended model:** Sonnet (flag: if perspective-correct texturing is wrong after one revision, escalate to a stronger model)

## Goal

Implement the real-time preview: a WebGL2 compositor that draws every active clip warped onto its surface, following the same rules as the Python renderer, usable both in the editor and fullscreen in the projector window.

## Files to create or modify

Under `studio/web/src/gl/`: `homography.ts`, `compositor.ts`, `sources.ts`, `shaders.ts`, tests `homography.test.ts`, `compositor.logic.test.ts`. Modify `projector/ProjectorPage.tsx` to register the live renderer (hook `setLiveRenderer` from T-030).

## Interfaces (copied from docs/05-interfaces.md §12)

```ts
// gl/homography.ts
export type Pt = [number, number];
export type Mat3 = [number, number, number, number, number, number, number, number, number]; // row-major
export function quadHomography(srcW: number, srcH: number, quad: Pt[]): Mat3;   // maps (0,0),(srcW,0),(srcW,srcH),(0,srcH) -> quad[0..3]
export function applyH(h: Mat3, p: Pt): Pt;
export function multiply(a: Mat3, b: Mat3): Mat3;
export function invert(h: Mat3): Mat3;
export function estimateAspect(quad: Pt[]): number;
export function fitRects(srcW: number, srcH: number, surfaceAspect: number, fit: "fill" | "fit" | "stretch"):
  { src: [number, number, number, number]; dst: [number, number, number, number] };   // (x0, y0, x1, y1)

// gl/compositor.ts
export class PreviewCompositor {
  constructor(canvas: HTMLCanvasElement, opts: { assetUrl: (assetId: string) => string });
  setProject(project: Project): void;
  render(tMs: number, playing: boolean): void;
  dispose(): void;
}
```

`fitRects` rules (identical to the backend), with `sa = srcW / srcH`, `ta = surfaceAspect`:

- `stretch`: src = whole source; dst = `(0, 0, 1, 1)`.
- `fill`: dst = `(0, 0, 1, 1)`; src = largest centred sub-rectangle of the source with aspect `ta` (if `sa > ta` crop width to `srcH * ta`, else crop height to `srcW / ta`).
- `fit`: src = whole source; if `sa > ta`: dst width 1, height `ta / sa`, centred vertically; else dst height 1, width `sa / ta`, centred horizontally.

## Compositing rules (copied from docs/02-architecture.md §6.2)

For time `t_ms`: start with opaque black. For each track from index 0 upward, for each clip with `start_ms ≤ t_ms < start_ms + duration_ms`:

1. Source time `s = in_offset_ms + (t_ms − start_ms)`; if `loop` and the asset has a duration, `s = s mod duration_ms`; non-looping past the end holds the last frame; images ignore `s`.
2. The content rectangle (`src` from `fitRects`) is mapped to the sub-rectangle `dst` of the surface's unit square, and the unit square is mapped to the surface quad by `quadHomography(1, 1, quad)`.
3. Alpha = source alpha × clip opacity × fade, where `fade = min(1, (t − start)/fade_in_ms) × min(1, (start + duration − t)/fade_out_ms)` (a zero-length fade counts as 1). The backend also multiplies by a feathered mask; the preview approximates feather (see below).
4. Blend `normal`: `dst = src·a + dst·(1−a)`; `add`: `dst = min(1, dst + src·a)`; `screen`: `dst = 1 − (1−dst)(1−src·a)`.
5. Surface id `"canvas"` is the full frame quad `(0,0),(W,0),(W,H),(0,H)` with aspect `W/H`.
6. Clips with a `generator` (v1) are skipped.

## Design

- One shader program. For each clip draw **the surface quad as two triangles in projector pixel space** and compute texture coordinates per fragment with the inverse homography, which is perspective-correct without tessellation:
  - Vertex shader: input `a_pos` (projector px); `gl_Position = vec4(a_pos.x / W * 2 − 1, 1 − a_pos.y / H * 2, 0, 1)`; pass `v_pos = a_pos`.
  - Fragment shader: `vec3 q = u_invH * vec3(v_pos, 1.0); vec2 uv = q.xy / q.z;` (`uv` in the surface unit square). Discard if outside `u_dst` rect. Map `uv` from `u_dst` to `u_src` (normalised source texture coordinates) and sample. Output premultiplied colour `rgb * a, a` with `a = texAlpha * u_opacity * feather`.
  - Feather approximation: `feather = smoothstep(0, f, distance to the nearest edge of the unit square measured in uv × approximate surface size in px)` where `f = feather_px`; pass `u_featherUv = vec2(feather_px / avgWidthPx, feather_px / avgHeightPx)`.
- `u_invH` = inverse of `quadHomography(1, 1, quad)` as a `mat3` (remember GLSL matrices are column-major: transpose the row-major `Mat3` when uploading).
- Blending with premultiplied output: `normal` → `gl.blendFunc(ONE, ONE_MINUS_SRC_ALPHA)`; `add` → `gl.blendFunc(ONE, ONE)`; `screen` → `gl.blendFunc(ONE_MINUS_DST_COLOR, ONE)`.
- Canvas backing size = project projector size (or a scaled size for the editor; set by the caller through the canvas `width`/`height`); the viewport always covers the whole canvas.
- `sources.ts`: per **clip** (not per asset) a `ClipTextureSource`:
  - Image: load once into a texture (`UNPACK_PREMULTIPLY_ALPHA_WEBGL` false; premultiply in the shader).
  - Video: hidden `<video muted playsInline preload="auto" crossOrigin="anonymous">` with `src = assetUrl(asset_id)`. On each `render`: compute `s` (seconds). If `playing`: ensure the element is playing and, if `|video.currentTime − s| > 0.08`, set `currentTime = s`; if paused: pause and set `currentTime = s` when it differs by more than 0.02. Upload with `gl.texImage2D(..., video)` only when `video.readyState >= 2`. Manual looping (do not use the `loop` attribute; `s` already wraps).
  - Sources for clips that are not active within the next 2 s are paused; sources are disposed when the clip disappears from the project.
- `setProject` diffs clips by id so editing one clip does not reload every video.
- Live renderer for the projector page: an object implementing `LiveRenderer` (from T-030: `start(projectId, canvas)`, `transport({playing, t_ms, revision})`, `stop()`), which creates its own `<canvas>` layered above the 2D canvas, fetches the project with `getProject`, refetches when `revision` changes, and runs a `requestAnimationFrame` loop. Its clock: on each `transport` message record `(t_ms, performance.now())`; while playing, `t = t_ms + elapsed`; while paused, `t = t_ms`.

## Pitfalls

- Texture coordinate origin: upload with `UNPACK_FLIP_Y_WEBGL` false and treat `uv.y = 0` as the top of the image, matching the top-left pixel origin used everywhere in this project.
- Non-power-of-two video textures need `CLAMP_TO_EDGE` and `LINEAR` (no mipmaps).
- `quadHomography` needs a 8×8 linear solve; implement Gaussian elimination with partial pivoting in `homography.ts` (no dependency). Degenerate quads: return the identity and let the caller skip drawing.
- Browsers block autoplay with sound; videos are always muted (audio comes from the timeline's audio element in T-034).
- jsdom has no WebGL: keep all decision logic (active clips, source time, fade, uniforms) in pure functions exported from `compositor.ts` (`activeClips(project, tMs)`, `sourceTimeMs(clip, asset, tMs)`, `fadeFactor(clip, tMs)`, `clipUniforms(project, clip, asset, srcW, srcH)`) and unit-test those.

## Acceptance

```
cd studio/web && pnpm lint && pnpm typecheck && pnpm test
```

Tests:

- `quadHomography(100, 50, q)` maps the four source corners to `q` within 1e-6; `invert(h)` composed with `h` is the identity (after normalising by the last element); `applyH` on the identity returns the input.
- `fitRects(1920, 1080, 1, "fill")` → src `[420, 0, 1500, 1080]`, dst `[0, 0, 1, 1]`; `fitRects(1920, 1080, 1, "fit")` → dst `[0, 0.21875, 1, 0.78125]`; `fitRects(100, 100, 2, "fit")` → dst `[0.25, 0, 0.75, 1]`.
- `activeClips` returns clips in track order and excludes clips outside their time range and generator clips.
- `sourceTimeMs`: looping clip on a 2000 ms asset at `t − start = 2500` with `in_offset_ms = 0` → 500; non-looping → 2500 (caller clamps); image → 0.
- `fadeFactor`: 0.5 halfway through a 1000 ms fade-in; 1 with zero fades; product of both ramps near a short clip's middle.
- `clipUniforms` for `stretch` on the canvas surface gives `dst = [0,0,1,1]`, `src = [0,0,1,1]` (normalised) and an `invH` that maps `(W, H)` to `(1, 1)`.

Visual correctness against the Python renderer is verified by T-037.
