## Steps

1. `FkError.__init__` stores `code` and `message` and calls `super().__init__(f"{code}: {message}")`.
2. `data_dir()` reads the environment on every call (no caching) so tests can change it with `monkeypatch.setenv`. Create directories with `mkdir(parents=True, exist_ok=True)`.
3. `new_id` uses `secrets.token_hex(4)`.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_foundation.py && uv run mypy src && uv run ruff check .
```

Tests must cover: `str(FkError("X","y")) == "X: y"`; `http_status("NOT_FOUND") == 404` and an unknown code gives 500; `data_dir()` honours `FACADEKIT_DATA` (use `tmp_path`) and creates `projects/` and `models/`; `new_id("srf")` matches `^srf_[0-9a-f]{8}$`; `slugify("Garage 2026!") == "garage-2026"`; `slugify("???") == "project"`; `unique_slug("Garage", {"garage", "garage-2"}) == "garage-3"`.
