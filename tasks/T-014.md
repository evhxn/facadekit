## Goal

Chain pre-check → capture → decode → maps → projector view into one function that writes the calibration files into a project folder, and provide "manual mode" which creates a blank calibration without scanning.

## Steps

`run_calibration`:

1. `spec = PatternSpec(*display.size, skip_lsb=settings.skip_lsb)`.
2. `camera.open()` inside `try/finally: camera.close()`.
3. Progress budget: precheck 0–0.05, capture 0.05–0.80 (wrap the capture's progress callback to rescale), decode 0.80–0.90, maps 0.90–0.97, writing 0.97–1.0. Messages: "Checking setup", "Pattern i of N", "Decoding", "Building map", "Saving".
4. After `build_maps`: if `maps.coverage < 0.50` raise `FkError("SCAN_FAILED", "Only {pct}% of the projection was measured.")` and write nothing.
5. Warnings list: `LOW_COVERAGE` if coverage < 0.85; `NON_PLANAR` if planarity < 0.5; `CAMERA_CONTROLS_UNAVAILABLE` if `capture.controls_applied.get("auto_exposure") is False`.
6. Write files into a temporary sibling folder `calibration/.tmp_<id>/` then `os.replace` it to `calibration/<id>/` so a crash never leaves a half-written calibration. Use `cv2.imwrite` for PNGs and `np.save` for the map.
7. Return the `Calibration`. Do **not** touch `project.json`.

`create_manual_calibration`: `mode="manual"`, camera/settings/quality/h_c2p all `None`; `proj_view.png` is a BGR `(40,40,40)` image with 1 px lines of `(90,90,90)` every 120 px in both directions and, at each crossing, the text `"x,y"` drawn with `cv2.putText` (`FONT_HERSHEY_SIMPLEX`, scale 0.4, colour `(140,140,140)`).

`load_calibration`: read and validate `calibration.json`; validate `calibration_id` against `^cal_[0-9a-f]{8}$` before building the path.

## Pitfalls

- The cancel flag must be checked between stages as well as inside capture; raise `FkError("CANCELLED", …)`.
- `cv2.imwrite` returns `False` instead of raising when the path is bad; check the return value and raise `FkError("INTERNAL", …)`.
- `h_c2p` must be stored as nested Python lists (`.tolist()`), not a NumPy array.

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_calib_pipeline.py && uv run mypy src && uv run ruff check .
```

Tests (simulator, `tmp_path` as the project folder, `sleep=lambda s: None`, `CalibSettings(discard_frames=0, average_frames=1)`):

- Successful scan: returns `mode == "scan"`, `quality.coverage > 0.85`, no warnings; all four files exist; `np.load(p2c.npy).shape == (1080, 1920, 2)`; `proj_view.png` loads as 1920×1080; `load_calibration` returns an equal model; progress values are non-decreasing and end at 1.0; the camera was closed (use a wrapper that records `close()`).
- Scene with a huge occluder covering 60 % of the projected area → `FkError` `SCAN_FAILED` and the `calibration/` folder contains no subfolder.
- Scene with a medium occluder (about 25 % of the area) → succeeds with warning `LOW_COVERAGE`.
- Manual: writes `calibration.json` and `proj_view.png` only; `mode == "manual"`.
- `load_calibration(tmp, "../x")` → `NOT_FOUND`.
