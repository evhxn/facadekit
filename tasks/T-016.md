# T-016 – Video reader and clip frame source

- **Milestone:** MVP
- **Recommended model:** Sonnet
- **Depends on:** T-015

## Goal

Decode video frames through an ffmpeg pipe at a fixed output frame rate, and wrap videos and images in one `ClipSource` class that returns "the frame at source time T" efficiently for the renderer.

## Files to create

- `studio/backend/src/facadekit/media/reader.py`
- `studio/backend/tests/test_media_reader.py`

## Interfaces (copied from docs/05-interfaces.md)

Available: `facadekit.media.ffmpeg.ffmpeg_exe() -> str`; `Asset` model (`kind`, `width`, `height`, `duration_ms`, `fps`, `has_alpha`); test fixtures `sample_video` (320×180, 30 fps, 2 s, `testsrc2`) and `sample_image` (64×48 PNG with alpha) in `tests/conftest.py`.

To implement:

```python
class VideoReader:
    def __init__(self, path: Path, *, fps: int, width: int, height: int, start_ms: int = 0) -> None: ...
        # ffmpeg -ss <start s> -i path -vf fps=<fps>,scale=<width>:<height> -pix_fmt bgr24 -f rawvideo -
    def read(self) -> np.ndarray | None: ...             # next frame (height, width, 3) uint8, or None at end
    def close(self) -> None: ...

class ClipSource:
    """Frame source for one asset, optimised for increasing times."""
    def __init__(self, asset: Asset, path: Path, *, fps: int, max_size: tuple[int, int]) -> None: ...
        # decodes at the asset's own size, but never larger than max_size (keeps aspect, never upscales)
    size: tuple[int, int]                                # decode size (width, height)
    def frame_at(self, source_ms: int) -> np.ndarray: ...
        # BGR (H, W, 3), or BGRA (H, W, 4) for images with alpha.
    def close(self) -> None: ...
```

## Steps

1. `VideoReader`: start `subprocess.Popen([ffmpeg_exe(), "-hide_banner", "-loglevel", "error", "-nostdin", "-ss", f"{start_ms/1000:.3f}", "-i", str(path), "-an", "-vf", f"fps={fps},scale={width}:{height}", "-pix_fmt", "bgr24", "-f", "rawvideo", "-"], stdout=PIPE, stderr=DEVNULL)`. `read()` reads exactly `width*height*3` bytes (loop until complete or EOF); a short read returns `None`. Return `np.frombuffer(...).reshape(height, width, 3)` (copy it so the buffer can be reused).
2. `close()`: close stdout, `terminate()`, `wait(timeout=5)`, then `kill()` if still alive. Idempotent. Implement `__enter__/__exit__` too.
3. `ClipSource` decode size: `scale = min(1, max_w / asset.width, max_h / asset.height)`; `w = max(2, round(asset.width * scale / 2) * 2)`, same for `h` (even numbers).
4. `ClipSource` for images: load once with `cv2.imread(IMREAD_UNCHANGED)`; gray → BGR; resize to `size` with `INTER_AREA`; `frame_at` always returns that array.
5. `ClipSource` for videos keeps `self._reader`, `self._index` (index of the last frame returned, in output-fps frames) and `self._last` (last frame array):
   ```
   target = source_ms * fps // 1000
   last_index = max(0, ceil(asset.duration_ms * fps / 1000) - 1); target = min(target, last_index)
   if reader is None or target < self._index or target > self._index + 2 * fps:
       reopen VideoReader(start_ms = target * 1000 // fps); self._index = target - 1
   while self._index < target:
       f = reader.read()
       if f is None: break            # past the real end: keep the last frame
       self._last = f; self._index += 1
   if self._last is None: return a black frame of `size`
   return self._last
   ```
6. `close()` closes the reader.

## Pitfalls

- `-ss` **before** `-i` seeks by keyframe then decodes accurately to the timestamp in modern ffmpeg, which is what we want. Do not put it after `-i` (slow).
- Reading from the pipe with `stdout.read(n)` may return fewer bytes than asked; loop.
- Forgetting to close readers leaks ffmpeg processes; tests must assert the process has exited after `close()`.
- The frame returned by `frame_at` is shared; callers must not modify it in place (document this in the docstring).

## Acceptance

```
cd studio/backend && uv run pytest -q tests/test_media_reader.py && uv run mypy src && uv run ruff check .
```

Tests:

- `VideoReader(sample_video, fps=30, width=320, height=180)` yields 58–61 frames of shape `(180, 320, 3)` then `None`; after `close()` the subprocess `poll()` is not `None`.
- `VideoReader(..., fps=15, ...)` yields 28–31 frames.
- `start_ms=1000` yields 28–31 frames at 30 fps.
- `ClipSource` on the video: `frame_at(0)` and `frame_at(1000)` differ (mean absolute difference > 1); `frame_at(1000)` called twice returns identical arrays; `frame_at(500)` after `frame_at(1500)` (backwards) works and equals a fresh source's `frame_at(500)`; `frame_at(99999)` returns the last frame without error.
- `ClipSource` with `max_size=(160, 90)` reports `size == (160, 90)`.
- `ClipSource` on the PNG returns a `(48, 64, 4)` array.
