# T-108 – Click-to-segment UI

- **Milestone:** v1
- **Recommended model:** Sonnet
- **Depends on:** T-101, T-106
- **Parallel with:** T-105, T-109, T-111

## Goal

Add a "Magic select" tool to the surface editor: the user clicks an object on the projector-view photo and gets a ready-made surface (outline + corners) to accept or refine.

## Files to create or modify

`studio/web/src/pages/surfaces/MagicSelect.tsx`, `pages/surfaces/SurfaceCanvas.tsx`, `pages/SurfacesPage.tsx`, `api/client.ts` (add `segment`), tests `pages/surfaces/MagicSelect.test.tsx`.

## Interfaces available

```ts
// backend: POST /api/v1/projects/{pid}/segment
//   body {"points": [{"x": number, "y": number, "label": 0 | 1}], "prefer"?: "auto" | "mobilesam" | "grabcut"}
//   -> {"outer": Pt[], "quad": Pt[], "score": number, "engine": "mobilesam" | "grabcut"}   (projector pixels; quad order TL,TR,BR,BL)
//   errors: 422 BAD_REQUEST ("Nothing was selected", or no calibration), MODEL_DOWNLOAD_FAILED, AI_UNAVAILABLE
interface Surface { id; name; quad: [Pt,Pt,Pt,Pt]; mask: {outer: Pt[]; holes: Pt[][]} | null; feather_px; aspect; mesh }
estimateAspect(quad): number            // pages/surfaces/geometry.ts
newId("srf"); useProjectStore.update(mutator); userMessage(code, fallback)
// SurfaceCanvas view transforms: toScreen(pt), toProjector(pt)
```

## Specification

1. Add `segment(pid, points, prefer?)` to the client.
2. Toolbar button "Magic select". While active: left click adds an include point (green dot), right click or Alt+click adds an exclude point (red dot); each click sends all points so far; the returned `outer` polygon is drawn as a translucent overlay and `quad` as a dashed outline with corner dots; a spinner shows while waiting ("First use downloads a small model, this can take a minute."). Only the latest response is applied (ignore out-of-order responses using a request counter).
3. Buttons: "Create surface" (Enter), "Undo last point" (Backspace), "Cancel" (Esc).
4. "Create surface" adds a surface with `quad` = returned quad, `mask` = `{outer, holes: []}` when the polygon has more than 4 points or differs from the quad by more than 3 % in area, otherwise `mask: null`; `aspect = estimateAspect(quad)`; `feather_px: 2`; name "Surface N". The new surface is selected and the tool closes.
5. Errors: `BAD_REQUEST` → "Nothing found there. Try clicking the middle of the object."; `MODEL_DOWNLOAD_FAILED` → retry automatically once with `prefer: "grabcut"` and show a small note "Using the simple selector (model download failed)."; network errors → standard banner.
6. A small badge shows which engine answered.
7. The tool is disabled with a tooltip in manual mode (no photo to analyse): detect `calibration.mode === "manual"`.

## Acceptance

```
cd studio/web && pnpm lint && pnpm typecheck && pnpm test
```

Tests (API mocked): a left click calls `segment` with one label-1 point in projector coordinates; a second right click sends two points with labels `[1, 0]`; a slow first response arriving after the second is ignored; "Create surface" stores a surface with the returned quad and a mask when the polygon has 9 points, and `mask: null` when the polygon equals the quad; `MODEL_DOWNLOAD_FAILED` triggers one retry with `prefer: "grabcut"`; the tool is disabled for a manual calibration.

## Out of scope

Automatic detection of all windows and doors (v2), box prompts, editing the mask (existing mask editor from T-101 is used afterwards).
