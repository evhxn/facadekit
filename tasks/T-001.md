# T-001 – Backend scaffold, Makefile and CI

- **Milestone:** MVP
- **Recommended model:** Haiku
- **Depends on:** none
- **Parallel with:** T-002

## Goal

Create the Python package skeleton for FacadeKit Studio's backend with linting, typing, tests, a root Makefile and CI, so later tickets only add modules.

## Context you need

FacadeKit is a local tool for holiday projection mapping. The backend is a Python 3.11+ package named `facadekit` at `studio/backend/`. Dependencies are managed with `uv`. The web UI (another ticket) lives in `studio/web/` and is managed with `pnpm`.

## Files to create

- `studio/backend/pyproject.toml`
- `studio/backend/src/facadekit/__init__.py` (`__version__ = "0.1.0"`)
- `studio/backend/src/facadekit/__main__.py`
- `studio/backend/src/facadekit/cli.py`
- `studio/backend/src/facadekit/webdist/.gitkeep`
- `studio/backend/tests/__init__.py`, `studio/backend/tests/test_cli.py`
- Empty `__init__.py` in each of these packages under `src/facadekit/`: `models`, `store`, `geom`, `devices`, `sim`, `calib`, `media`, `render`, `fpp`, `jobs`, `api`, `ai`
- `Makefile` (repo root), `.gitignore` (repo root), `.github/workflows/ci.yml`
- `LICENSE` (repo root): the unmodified GPL-3.0 text, plus `README.md` with one line: `# FacadeKit` and "See docs/."

## Specification

`pyproject.toml`:

- Build backend `hatchling`; package dir `src/facadekit`; include `src/facadekit/webdist/**` in the wheel.
- `requires-python = ">=3.11"`, licence `GPL-3.0-or-later`.
- Dependencies: `fastapi`, `uvicorn[standard]`, `pydantic>=2`, `numpy`, `opencv-python-headless`, `imageio-ffmpeg`, `httpx`, `python-multipart`.
- Optional extra `ai`: `librosa`, `onnxruntime`.
- Dev group: `pytest`, `ruff`, `mypy`.
- Script entry: `facadekit = "facadekit.cli:main"`.
- Ruff: line length 100, rules `E,F,I,UP,B`. Mypy: `strict = true`, `files = ["src"]`, and `ignore_missing_imports = true` for `cv2`, `imageio_ffmpeg`, `librosa`, `onnxruntime`.

`cli.py` for now: `main(argv: list[str] | None = None) -> int` using `argparse` with subcommands declared but only `--version` working. Subcommand names to declare (each prints "not implemented" to stderr and returns 2 for now): `serve`, `new`, `calibrate`, `render`, `publish`, `doctor`, `sim`. `__main__.py` does `raise SystemExit(main())`.

Makefile targets:

```
setup:      cd studio/backend && uv sync --all-extras ; cd studio/web && pnpm install   (skip the web part if studio/web/package.json is missing)
lint:       cd studio/backend && uv run ruff check . && uv run ruff format --check . && uv run mypy src ; web: pnpm lint && pnpm typecheck (if present)
test:       cd studio/backend && uv run pytest -q ; web: pnpm test (if present)
build-web:  cd studio/web && pnpm build
dev:        prints the two commands to run: `uv run facadekit serve --no-browser` and `pnpm dev`
```

CI (`ci.yml`): on push and pull request; matrix `ubuntu-latest`, `macos-latest`, `windows-latest`; steps: checkout, install `uv` (astral-sh/setup-uv), `uv sync --all-extras` in `studio/backend`, ruff, mypy, pytest. A second job on ubuntu only sets up Node 20 + pnpm and runs `pnpm install && pnpm lint && pnpm typecheck && pnpm test` in `studio/web` guarded by `if: hashFiles('studio/web/package.json') != ''`.

`.gitignore`: `__pycache__/`, `.venv/`, `node_modules/`, `dist/`, `*.fkproj/`, `studio/backend/src/facadekit/webdist/*` with `!.gitkeep`, `.mypy_cache/`, `.ruff_cache/`, `.pytest_cache/`.

## Pitfalls

- Use the `src/` layout so tests import the installed package, not the folder.
- On Windows `make` may be missing in CI; CI calls the `uv` commands directly, not `make`.

## Acceptance

```
cd studio/backend && uv sync --all-extras
uv run facadekit --version            # prints 0.1.0
uv run python -m facadekit --version  # prints 0.1.0
uv run ruff check . && uv run ruff format --check . && uv run mypy src
uv run pytest -q                      # test_cli.py: --version exits 0 and prints 0.1.0; unknown subcommand exits 2
```

## Out of scope

Any real functionality, the web project, Docker, release automation.
