# T-010 – Gray-code pattern generation

- **Milestone:** MVP

## Goal

Generate the sequence of black-and-white stripe images (Gray code) that the projector shows during calibration.

## Background

To learn which projector pixel each camera pixel sees, we project stripe images that encode each projector column number (then each row number) in binary Gray code, one bit per image. Each bit image is followed by its inverse so the decoder can compare the pair instead of using a fixed threshold. The finest `skip_lsb` bits are not projected because cheap webcams cannot resolve them.

## Interface (copied from docs/05-interfaces.md) – implement exactly

```python
@dataclass(frozen=True)
class PatternSpec:
    width: int
    height: int
    skip_lsb: int = 2

@dataclass(frozen=True)
class PatternFrame:
    kind: Literal["black", "white", "pattern"]
    axis: Literal["x", "y"] | None = None
    bit: int | None = None            # bit index in the Gray code, 0 = least significant
    inverse: bool = False

def bits_for(n: int) -> int                       # ceil(log2(n)); bits_for(1920) == 11, bits_for(1024) == 10
def pattern_sequence(spec: PatternSpec) -> list[PatternFrame]
    # [black, white] + for axis in ("x","y"): for bit in range(bits-1, skip_lsb-1, -1): [pattern, inverse]
    # bits = bits_for(width) for axis "x", bits_for(height) for axis "y"
def render_pattern(spec: PatternSpec, frame: PatternFrame) -> np.ndarray   # uint8 (height, width), values 0 or 255
def gray_to_binary(g: np.ndarray) -> np.ndarray   # elementwise on integer arrays
```

Pixel rule for a `pattern` frame on axis `x`, bit `b`: for projector column `c`, `g = c ^ (c >> 1)`; the pixel is 255 if `(g >> b) & 1` else 0; every row is identical. Axis `y` uses the row index and every column is identical. `inverse=True` swaps 0 and 255. `black` is all 0, `white` all 255.

## Steps

1. `bits_for(n)`: `max(1, (n - 1).bit_length())`.
2. `render_pattern`: build a 1-D index with `np.arange`, compute the bit line, then `np.tile`/broadcast to 2-D. Return a contiguous `uint8` array.
3. `gray_to_binary`: `b = g.copy(); shift = 1; while shift < 32: b ^= b >> shift; shift *= 2`. Works for arrays of `int32`/`int64`.
4. Validate: `skip_lsb` must satisfy `0 <= skip_lsb < min(bits_x, bits_y)`, else `ValueError`.
