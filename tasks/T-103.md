# T-103 – Audio waveform on the timeline

- **Milestone:** v1
- **Recommended model:** Haiku
- **Depends on:** T-102
- **Parallel with:** T-104, T-106, T-110

## Goal

Draw the show audio's waveform as a row at the bottom of the timeline so users can line clips up with the music by eye.

## Files to create or modify

`studio/web/src/pages/arrange/Waveform.tsx`, `pages/arrange/peaks.ts` (+ test), `pages/arrange/Timeline.tsx` (add the row).

## Interfaces available

```ts
// project.timeline.audio_asset_id: string | null ; assetUrl(pid, aid): string  (api/client.ts)
// timelineMath.ts (T-102): msToX(ms, view), xToMs(x, view); the timeline passes { pxPerMs, scrollLeftPx, widthPx }
```

## Specification

1. `peaks.ts`: `async function loadPeaks(url: string, bucketsPerSecond = 200): Promise<{ min: Float32Array; max: Float32Array; durationMs: number; bucketsPerSecond: number }>` — `fetch` the file, `AudioContext.decodeAudioData`, mix channels to mono, and compute per-bucket min and max. Pure helper `computePeaks(samples: Float32Array, sampleRate: number, bucketsPerSecond: number)` does the math and is unit-tested. Cache results in a `Map` keyed by URL.
2. `Waveform.tsx`: a canvas 64 px high spanning the timeline width; for each visible pixel column draw a vertical line from the min to the max of the buckets it covers; colour from a CSS variable; redraw on scroll, zoom and resize (use `ResizeObserver`); handle `devicePixelRatio`.
3. While decoding, show "Loading waveform…". On decode failure show "Waveform unavailable" (the show still plays).
4. Do **not** add the `wavesurfer.js` dependency; this small custom drawing replaces it (it must stay in sync with our own zoom/scroll).
5. No audio asset selected → the row is hidden.

## Acceptance

```
cd studio/web && pnpm lint && pnpm typecheck && pnpm test
```

Tests: `computePeaks` on a 1 s, 1 kHz sine at 8 kHz sample rate with 100 buckets/s returns 100 buckets with max ≈ 1 and min ≈ −1; on silence returns zeros; bucket count is `ceil(durationSeconds * bucketsPerSecond)`; a ramp signal gives monotonically increasing `max`.

## Out of scope

Beat markers (T-105), audio editing, multiple audio tracks, spectrograms.
