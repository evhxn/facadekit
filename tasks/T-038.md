## Goal

Write the repository README and the first user-facing guide so that a hobbyist decorator can install FacadeKit, complete the wizard, and play a mapped video from Falcon Player (FPP).

## Audience

Home holiday decorators. They can follow steps and plug in cables; many have used xLights and FPP; most are not programmers. Write short sentences, one action per step, no jargon without a one-line explanation. Do not promise features that are not in the MVP.

## Facts to use (do not invent others)

- FacadeKit is free and open source (GPL-3.0-or-later). It runs on Windows, macOS and Linux. It needs Python 3.11 or newer and Chrome, Edge or Firefox.
- Install: `pipx install facadekit` (or `uvx facadekit serve`). Start: `facadekit serve` opens `http://localhost:8137` in the browser. `facadekit doctor` prints diagnostic information to include in bug reports.
- Hardware: a laptop or desktop; any HDMI projector; a USB webcam; a Raspberry Pi (3 or newer) running FPP version 10 or newer on the same network.
- Workflow, in order:
  1. Put the projector in its final position. Turn off keystone and digital zoom. Let it warm up for 2 minutes.
  2. Connect the projector to the laptop with HDMI. Set that display to the projector's native resolution and 100 % scaling.
  3. Create a project and choose the projector's native resolution.
  4. Setup → open the projector window, drag it to the projector screen, click to go fullscreen. A grid appears on the house.
  5. Place the webcam next to the projector so it sees the whole grid. Fix it in place.
  6. Wait until dusk or night. Click Start scan (about 30 seconds). Do not walk in front of the projector.
  7. Surfaces → click the four corners of the garage door (top-left, top-right, bottom-right, bottom-left). Nudge corners with the arrow keys while watching the outline on the real door.
  8. Arrange → import a video, add a clip on the surface, press Play to preview on the house.
  9. Publish → Render show → enter the FPP address (for example `fpp.local`) → Send to FPP.
  10. Move the HDMI cable from the laptop to the Raspberry Pi. Run "alignment check" if the picture looks shifted.
- Manual mode: if the scan fails, "Skip scan" lets the user place surfaces by eye using the live outlines.
- Videos with a black background (typical for purchased holiday projection videos) look best with blend mode Add or Screen.
- Users must respect the licence of media they bought; FacadeKit never uploads media anywhere except to the user's own FPP.
- Simulator mode for trying the software without hardware: `facadekit serve --sim`.

Troubleshooting entries (problem → cause → fix), taken from the design:

| Problem | Fix |
|---|---|
| "Your computer is not sending the projector its native resolution" | Set the projector display to the native resolution and 100 % scaling in the OS display settings; reset browser zoom to 100 % in the projector window. |
| "It is too bright to scan" | Wait until after sunset; turn off porch lights; or use manual mode. |
| "The camera cannot see the projection" | Move or turn the camera until the whole grid is in the live view. |
| Red areas after the scan | The camera could not see those areas (tree, shadow, dark paint). Move the camera closer to the projector and scan again, or align those surfaces by eye. |
| "Something moved during the scan" / scan fails repeatedly | Fix the camera and projector firmly; scan again. |
| Picture is shifted when played from the Pi | Set FPP's HDMI output to the projector's native resolution; turn off overscan/zoom on the projector; send the alignment check again. |
| Video stutters on a Raspberry Pi 3 | Render with "Raspberry Pi – lighter (720p)". |
| "Could not reach FPP" | Check the address; the laptop and Pi must be on the same network; try the IP address instead of `fpp.local`. |
| "FPP is too old" | Update FPP to version 10 or newer. |
| Projector was bumped | Re-do the scan, then check each surface's corners. |

## Structure

- `README.md`: what it is (3 sentences), what you need, install, a 10-line quick start linking to the full guide, simulator mode, project status ("early MVP"), licence, how to get help (GitHub Issues, include `facadekit doctor` output), link to `CONTRIBUTING.md`. Developer section: `make setup`, `make test`, `make dev`, link to `docs/04-repo-structure.md`.
- `quick-start.md`: the 10 steps expanded, each with an "You should see…" line. Use placeholders `![screenshot: <description>](img/<name>.png)` where screenshots will go (do not create image files).
- `troubleshooting.md`: the table above as sections.
- `glossary.md`: projector view, surface, native resolution, keystone, FPP, playlist, render, alignment check, blend mode (one or two sentences each).
- `CONTRIBUTING.md`: tickets live in `tasks/`; one branch per ticket; run `make lint test` before a pull request; contracts are in `docs/05-interfaces.md` and must not be changed without discussion; contributions are licensed GPL-3.0-or-later (Developer Certificate of Origin sign-off: `git commit -s`).
