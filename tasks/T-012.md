# T-012 – Gray-code decoding

- **Milestone:** MVP

## Goal

From the captured pattern images, compute for every camera pixel the projector pixel that illuminated it, with a validity mask.

To implement:

```python
@dataclass
class DecodeResult:
    c2p: np.ndarray                   # float32 (Hc, Wc, 2); NaN where invalid; [...,0]=proj x, [...,1]=proj y
    valid: np.ndarray                 # bool (Hc, Wc)
    contrast: np.ndarray              # float32 (Hc, Wc) = white - black
    lit_fraction: float
    median_contrast: float

def decode(capture: CaptureSet, *, min_conf: float = 0.10, outlier_px: float = 8.0) -> DecodeResult
```

## Algorithm

```
black = image of the frame with kind "black"; white = kind "white"
contrast = white - black
lit = contrast > max(12.0, 0.15 * percentile(contrast, 95))

for axis in ("x", "y"):
    bits = bits_for(width if axis == "x" else height)
    value_gray = zeros(int32); conf = full(+inf)
    for b in range(bits - 1, skip_lsb - 1, -1):            # MSB first
        d = image(axis, b, inverse=False) - image(axis, b, inverse=True)
        conf = minimum(conf, abs(d) / maximum(contrast, 1.0))
        value_gray = (value_gray << 1) | (d > 0)
    # value_gray now holds the top (bits - skip_lsb) Gray bits. Convert, then restore the scale:
    value = gray_to_binary(value_gray)
    coord[axis] = (value << skip_lsb) + (1 << skip_lsb) / 2.0       # centre of the cell; with skip_lsb=0 add 0.5

valid = lit & (conf_x > min_conf) & (conf_y > min_conf) & (coord_x < width) & (coord_y < height)

# outlier rejection: compare each pixel with the local median of valid neighbours
for axis: med = median of coord over a 5x5 window (see pitfalls); valid &= abs(coord - med) <= outlier_px

c2p = stack([coord_x, coord_y], -1).astype(float32); c2p[~valid] = NaN
lit_fraction = lit.mean(); median_contrast = median(contrast[lit]) (0.0 if nothing is lit)
```

Why converting the truncated Gray value works: the top `k` bits of a Gray code are the Gray code of the top `k` bits of the binary number, so `gray_to_binary` of the truncated value equals `column >> skip_lsb`.

## Pitfalls

- Look frames up by `(kind, axis, bit, inverse)` through a dict built from `capture.frames`; do not assume positions.
- 5×5 median with invalid pixels: fill invalid pixels with the result of `cv2.medianBlur` is not NaN-aware. Simple robust approach: `tmp = coord.astype(float32); tmp[~valid] = -1e6`; `med = cv2.medianBlur(tmp, 5)`; where `med < -1e5` (most neighbours invalid) mark the pixel invalid. `cv2.medianBlur` with `ksize=5` supports `float32` single-channel images.
- Do everything vectorised; no Python loops over pixels. Target under 2 s for 38 frames at 1280×720.
- Missing black or white frame in the capture → `FkError("SCAN_FAILED", "Capture set is incomplete")`.

```
cd studio/backend && uv run pytest -q tests/test_calib_decode.py && uv run mypy src && uv run ruff check .
```

Tests:

- **Synthetic exact test**: spec 256×128 with `skip_lsb=0`. Build a fake `CaptureSet` whose "camera" is the projector itself: `images[i] = render_pattern(spec, frame).astype(float32)`. Decode: every pixel valid; `c2p[y, x] == (x + 0.5, y + 0.5)` exactly.
- Same with `skip_lsb=2`: `abs(c2p[...,0] - (x + 0.5)) <= 2.0` everywhere and likewise for y.
- **Simulator test**: capture `default_scene()` with `run_capture` (`sleep=lambda s: None`, `CalibSettings(discard_frames=0, average_frames=1)`). Ground truth for camera pixel `(u, v)` is `inv(scene.h_p2c)` applied to `(u, v)`. Over valid pixels the median absolute error is below 3 px on each axis and the 95th percentile is below 6 px; `valid.mean() > 0.15`.
- Simulator with an occluder over the garage door: fewer than 5 % of camera pixels inside the door region are valid.
- A capture set without the white frame raises `FkError` `SCAN_FAILED`.
