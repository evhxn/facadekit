# T-002 – Web UI scaffold

- **Milestone:** MVP
- **Recommended model:** Haiku
- **Depends on:** none
- **Parallel with:** T-001

## Goal

Create the React + TypeScript + Vite project for the FacadeKit Studio web UI with lint, type-check, unit tests, a dev proxy to the backend, and a build that outputs into the Python package.

## Files to create

Under `studio/web/`: `package.json`, `vite.config.ts`, `tsconfig.json`, `.eslintrc.cjs`, `.prettierrc`, `index.html`, `src/main.tsx`, `src/App.tsx`, `src/routes.tsx`, `src/App.test.tsx`, `src/vite-env.d.ts`, and placeholder pages `src/pages/ProjectsPage.tsx`, `SetupPage.tsx`, `SurfacesPage.tsx`, `ArrangePage.tsx`, `PublishPage.tsx`, `src/projector/ProjectorPage.tsx` (each renders an `<h1>` with its name).

## Specification

- Package manager `pnpm`, Node 20+. Runtime deps: `react@18`, `react-dom@18`, `react-router-dom@6`, `zustand`. Dev deps: `vite`, `@vitejs/plugin-react`, `typescript`, `vitest`, `@testing-library/react`, `jsdom`, `eslint` with `@typescript-eslint` and `eslint-plugin-react-hooks`, `prettier`.
- Scripts: `dev` (vite), `build` (`tsc --noEmit && vite build`), `lint` (`eslint src --max-warnings 0`), `typecheck` (`tsc --noEmit`), `test` (`vitest run`).
- `tsconfig.json`: `strict: true`, `noUncheckedIndexedAccess: true`, `jsx: react-jsx`, target ES2022.
- `vite.config.ts`: `build.outDir = "../backend/src/facadekit/webdist"`, `emptyOutDir: true`; dev server port 5173 with proxy: `/api` → `http://127.0.0.1:8137`, `/ws` → `ws://127.0.0.1:8137` (`ws: true`). Vitest environment `jsdom`.
- Routes (`routes.tsx`, React Router):

| Path | Page |
|---|---|
| `/` | `ProjectsPage` |
| `/p/:projectId/setup` | `SetupPage` |
| `/p/:projectId/surfaces` | `SurfacesPage` |
| `/p/:projectId/arrange` | `ArrangePage` |
| `/p/:projectId/publish` | `PublishPage` |
| `/projector` | `ProjectorPage` (no app chrome: no header, black background, no scrollbars) |

- `App.tsx`: header with the text "FacadeKit" and, when a project route is active, four nav links (Setup, Surfaces, Arrange, Publish). The `/projector` route renders without the header.
- Styling: CSS modules. Global CSS: `body { margin: 0; font-family: system-ui; }`.

## Pitfalls

- `emptyOutDir` would delete `webdist/.gitkeep`; add a tiny Vite plugin or a `postbuild` script that re-creates `.gitkeep`.
- Keep `any` out; ESLint must pass with zero warnings.

## Acceptance

```
cd studio/web && pnpm install
pnpm lint && pnpm typecheck
pnpm test          # App.test.tsx: renders "FacadeKit"; "/projector" route renders without the header
pnpm build         # creates ../backend/src/facadekit/webdist/index.html
```

## Out of scope

Real pages, API calls, state management, WebGL.
