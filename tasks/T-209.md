# T-209 – FacadeKit FPP plugin: projector control on the Pi

- **Milestone:** v1.1 show operation (docs/20)
- **Depends on:** T-117 (FPP audit, docs/17)
- **Parallel with:** none

## Goal

A native FPP 10.4 plugin (`integrations/fpp-plugin/`) that switches PJLink class 1 projectors
(several, in parallel, warm-up and cool-down aware but instant by default for laser models),
offers FPP Commands for playlists/scheduler/presets, optional automatic power and a fault guard,
a settings/status/log page, token-protected REST routes, and a store of the shows FacadeKit
published. FacadeKit gets a client, a fake plugin, publish integration, a status card, CLI
commands and S-1 recorder steps, and keeps working without the plugin.

## Interfaces (new ⚑)

docs/05 §8 and §11, tagged T-209: `publish` body `power_on`, job result `plugin`;
`GET /fpp/plugin`, `POST|DELETE /fpp/plugin/pair`, `POST /fpp/plugin/projectors`;
`facadekit fpp plugin-status`, `facadekit fpp fake-pjlink`. Plugin routes: docs/20 §3.5.
