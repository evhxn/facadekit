# T-007 – Mask rasterisation

- **Milestone:** MVP

- **Depends on:** T-001

## Goal

Turn a polygon (with optional holes) in projector pixels into a soft-edged alpha mask image used by the renderer.

## Files to create

- `studio/backend/src/facadekit/geom/mask.py`
- `studio/backend/tests/test_geom_mask.py`

## Interface (copied from docs/05-interfaces.md)

```python
Point = tuple[float, float]

def rasterize_mask(width: int, height: int, outer: Sequence[Point],

    # then if feather_px > 0: cv2.GaussianBlur with sigma = feather_px / 2.
```

## Steps

1. Create `canvas = np.zeros((height, width), np.uint8)`.
2. Use sub-pixel precision: `shift = 4`; convert points to `np.round(pts * 16).astype(np.int32)` and call `cv2.fillPoly(canvas, [pts], 255, lineType=cv2.LINE_AA, shift=4)`.
3. For each hole call `cv2.fillPoly(canvas, [hole_pts], 0, lineType=cv2.LINE_AA, shift=4)`.
4. Convert to `float32 / 255`.
5. If `feather_px > 0`: `cv2.GaussianBlur(mask, (0, 0), sigmaX=feather_px / 2)`.
6. Fewer than 3 outer points → `FkError("BAD_REQUEST", …)` (import from `facadekit.errors`). Points may lie outside the image; that is fine.

Tests:

- Square `(10,10),(50,10),(50,50),(10,50)` on a 64×64 canvas: value at `(30,30)` is 1.0, at `(5,5)` is 0.0, dtype `float32`, shape `(64, 64)`; total sum within 3 % of 1600.
- With a hole `(20,20),(40,20),(40,40),(20,40)`: value at `(30,30)` is 0.0 and at `(15,15)` is 1.0.
- With `feather_px=8`: value at the edge midpoint `(10,30)` is between 0.3 and 0.7; all values within 0..1.
- Two points raise `FkError` with code `BAD_REQUEST`.

## Out of scope

Mask editing, mesh warp, scaling masks (callers scale the points).
