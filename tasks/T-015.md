## Goal

Locate the bundled ffmpeg binary, run it safely, identify imported media files (video, image or audio, with size/duration/fps), and make thumbnails.

`Asset` (from `facadekit.models.project`): `id, kind ("video"|"image"|"audio"), filename, original_name, width, height, duration_ms, fps, has_audio, has_alpha`. For audio `width/height/fps` are `None`; for images `duration_ms/fps` are `None`.

## Steps

1. `run_ffmpeg(args)`: `subprocess.run([ffmpeg_exe(), "-hide_banner", "-loglevel", "error", "-nostdin", *args], capture_output=True, timeout=timeout)`. Non-zero exit → `FkError("FFMPEG_FAILED", last 500 characters of stderr)`. Timeout → same code.
2. Also provide `ffmpeg_info(path: Path) -> str`: runs `ffmpeg -hide_banner -i <path>` (which exits non-zero by design) and returns stderr text. Used for parsing.
3. `probe` classification by lower-cased extension:
   - Images `.png .jpg .jpeg .webp .bmp`: `img = cv2.imread(str(path), cv2.IMREAD_UNCHANGED)`; `None` → `UNSUPPORTED_MEDIA`. `has_alpha = img.ndim == 3 and img.shape[2] == 4`.
   - Audio `.mp3 .wav .m4a .flac .ogg .aac`: parse `Duration: HH:MM:SS.xx` from `ffmpeg_info`; no match → `UNSUPPORTED_MEDIA`. `has_audio=True`.
   - Anything else is treated as video: parse from `ffmpeg_info` the line containing `Video:` for `(\d{2,5})x(\d{2,5})` and `([\d.]+) fps` (fall back to `([\d.]+) tbr`), the `Duration:` line, and `has_audio = "Audio:" in text`. No video stream → `UNSUPPORTED_MEDIA` with message "Not a video, image or audio file ffmpeg can read".
   - Duration `N/A` for a video → `UNSUPPORTED_MEDIA`.
4. Rotation: if the stream text contains `rotate` / `displaymatrix: rotation of -90` or `90`, swap width and height (phone videos). ffmpeg auto-rotates on decode, so the swapped size is what readers will get.
5. `make_thumbnail`: image → `cv2.imread`, drop alpha, resize to width 320 with `INTER_AREA`, `cv2.imwrite` quality 80. Video → `run_ffmpeg(["-y", "-ss", "1", "-i", path, "-frames:v", "1", "-vf", "scale=320:-2", out_path])`; if that fails or the output is missing (clip shorter than 1 s) retry with `-ss 0`. Audio → `FkError("BAD_REQUEST")`.

## Pitfalls

- `imageio-ffmpeg` ships **no ffprobe**. Everything must be parsed from `ffmpeg -i` stderr.
- Paths with spaces and non-ASCII characters: always pass arguments as a list, never through a shell.
- Regex for fps must not capture the bitrate (`kb/s`); anchor on the literal ` fps`.
