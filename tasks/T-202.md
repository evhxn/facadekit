# T-202 – Camera quality measurements and verdict

- **Milestone:** v1.1 camera quality (docs/08 §3)
- **Recommended model:** Sonnet
- **Depends on:** T-201
- **Parallel with:** none

## Goal

Measure, before and after a scan, whether the camera sees the projection with enough detail. Turn that into a verdict ("good", "marginal", "too_coarse") with reasons. Stop refusing small projections: a far camera now gets an honest verdict instead of `CAMERA_NO_PROJECTION`.

## Files to create or modify

- Create `studio/backend/src/facadekit/calib/quality.py`, `tests/test_calib_quality.py`
- Modify `calib/capture.py` (`precheck`), `calib/pipeline.py` (`run_calibration_from_capture` gate, quality fields), `models/calibration.py` (`CalibQuality` optional fields) ⚑

## Interfaces (new; contract additions ⚑ listed in docs/08 §7)

```python
# calib/quality.py
STRIPE_MIN_CAM_PX = 3.0      # finest stripe must span this many camera px
MOD_OK = 0.25                # stripe modulation needed to call a bit readable (tuned in step 5)
SNR_LOW = 8.0
MIN_LIT_PX = 4000
CLIP_LEVEL = 250.0

@dataclass
class LitBlob:
    mask: np.ndarray            # bool (Hc, Wc): largest component after 3x3 opening
    box: tuple[int, int, int, int]   # x0, y0, x1, y1 (pixel-corner, x1/y1 exclusive)
    area_px: int                # pixels in the blob
    hull_area_px: float         # convex hull area of the blob (cv2.convexHull + cv2.contourArea)
    total_lit_px: int           # all lit pixels before taking the largest component

def lit_threshold(contrast: np.ndarray) -> float          # max(12, 0.15 * p95(contrast)) (same rule as decode)
def lit_blob(contrast: np.ndarray) -> LitBlob | None      # None when nothing is lit
def projection_found(blob: LitBlob | None) -> bool        # area_px >= MIN_LIT_PX and area_px >= 0.5 * total_lit_px
def px_per_proj_px(hull_area_px: float, proj_w: int, proj_h: int) -> float   # sqrt(hull / (W*H))
def px_per_proj_px_from_h(h_c2p: np.ndarray, proj_w: int, proj_h: int) -> float
    # J = Jacobian of inv(h_c2p) (projector -> camera) at (W/2, H/2); sqrt(|det J|)
def finest_readable_skip(s: float) -> int                 # clamp(ceil(log2(STRIPE_MIN_CAM_PX / s) - 1e-9) - 1, 0, 6)
def stripe_modulation(pattern: np.ndarray, inverse: np.ndarray, contrast: np.ndarray, lit: np.ndarray) -> float
    # median over lit of |pattern - inverse| / max(contrast, 1)
def noise_sigma(frame_a: np.ndarray, frame_b: np.ndarray, lit: np.ndarray) -> float   # std(a - b over lit) / sqrt(2)
def probe_stripes(display, camera, spec: PatternSpec, settings: CalibSettings, *, bits=(2, 3, 4),
                  sleep=time.sleep) -> dict[int, float]
    # for each bit: show x-axis pattern and inverse (render_pattern with PatternFrame("pattern","x",bit,inv)),
    # capture each like capture._shoot, return {bit: stripe_modulation}; uses BLACK/WHITE shot first for contrast
Verdict = Literal["good", "marginal", "too_coarse"]
Reason = Literal["SMALL_IN_FRAME", "BLURRY", "NOISY", "CLIPPED", "NO_EXPOSURE_CONTROL"]
def verdict(s: float, snr: float, *, modulation: dict[int, float] | None = None,
            p99_white: float | None = None, controls: dict[str, bool] | None = None) -> tuple[Verdict, list[Reason]]
```

Verdict rule (normative, docs/08 §3):

```
skip_scale = finest_readable_skip(s)
skip_blur  = None if modulation is None else min([b for b in sorted(modulation) if modulation[b] >= MOD_OK], default=5)
need = max(skip_scale, skip_blur or 0)
verdict = "good" if need <= 2 else "marginal" if need == 3 else "too_coarse"
reasons: SMALL_IN_FRAME if skip_scale >= 3; BLURRY if skip_blur is not None and skip_blur >= 3;
         NOISY if snr < SNR_LOW (and then verdict is at least "marginal");
         CLIPPED if p99_white is not None and p99_white >= CLIP_LEVEL;
         NO_EXPOSURE_CONTROL if controls and controls.get("auto_exposure") is False
order of reasons: as listed.
```

## Steps

1. Implement `quality.py`. Pure NumPy/OpenCV; `probe_stripes` is the only function touching devices.
2. `precheck` (capture.py):
   - Compute `contrast` as today, then `blob = lit_blob(contrast)`.
   - Replace the `lit_fraction < 0.05` test by `not projection_found(blob)`, which raises `CAMERA_NO_PROJECTION` with the existing message.
   - `median_contrast` stays exactly as today (over all lit pixels): it feeds the scan-memory lighting bucket and must not drift. Keep the `TOO_BRIGHT` test.
   - After the WHITE shot, read two more single frames with `camera.read()`, convert to gray float32 and compute `snr = median_contrast / max(noise_sigma(a, b, blob.mask), 0.1)`.
   - Return the old keys (`lit_fraction` is still the fraction of all lit pixels in the frame) plus `lit_px`, `px_per_proj_px`, `snr`, `p99_white`, `lit_x0`, `lit_y0`, `lit_x1`, `lit_y1` (all floats).
3. `pipeline.run_calibration_from_capture`: replace its `pre["lit_fraction"] < 0.05` test with the same blob rule. `_contrast_stats` returns the same extra keys, with `snr` left out because a recording has no repeated frames. In `_decode_capture`, fill `px_per_proj_px` from `px_per_proj_px_from_h(maps.h_c2p, …)` when `h_c2p` exists, else from `pre`. Fill `snr` from `pre.get("snr")` and `verdict` from `verdict(s, snr or inf)` (no modulation inside a scan).
4. Existing callers of `precheck` must keep working: it still returns `dict[str, float]` and the old keys keep their meaning.
5. **Tune `MOD_OK`.** Write a test helper (not shipped) that, for each of the 18 `sim.learn_eval.make_scenes(18)` scenes, runs `probe_stripes` on `SimDisplay`/`SimCamera` and compares `skip_blur <= 2` with "standard succeeds" (use `learn_eval.scan_once(scene, get_strategy("standard"))`, success = record ok). Choose `MOD_OK` in [0.15, 0.40] (step 0.05) maximising agreement. Put the agreement table in the PR and in docs/08 §6 under a "Tuning result" line.

## Pitfalls

- Use the **same** lit threshold function in precheck, `_contrast_stats` and (later) decode; do not fork the rule.
- `cv2.connectedComponentsWithStats` on a uint8 mask; open with a 3×3 kernel first so single noisy pixels do not join. If `total_lit_px == 0` return None.
- `finest_readable_skip` at exact boundaries: `s = 0.375` must give 2 (use the 1e-9 tolerance).
- The probe uses the projector: keep the frame order BLACK, WHITE, then pattern/inverse per bit, with the usual settle and discard from `settings`.
- `pipeline.py` and `learn.py` may have uncommitted edits from other work on this branch; rebase and keep their behaviour.
